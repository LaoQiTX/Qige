# 验证说明

当前测试版为 0.1.0-beta.8。功能实现、自动回归和真实系统验收分别记录，避免将模拟通过理解为所有电脑上已稳定。

## 自动与隔离检查

| 入口 | 覆盖 |
| --- | --- |
| `SelfTest` | 数据位置、原子保存、兼容迁移、重解析点、冲突和中断 |
| `StorageTest` | 收纳/同步/归还、完整副本确认、下载来源流和拖出解除分组 |
| `LayoutTest` | 抽屉所有权、移除归档、DPI、吸附、尺寸与可见工作区 |
| `P0Test` | 后台 STA、串行顺序、图标请求合并/容量、恢复退避、布局合并和采样 |
| `ManagerTest` | 真实 WPF 配隔离样例：搜索、内容、批量收纳、恢复中心与退出 |
| `ResidentTest` | 托盘与环境消息、20 次隔离宿主销毁/重建 |
| `StorageRenderTest` | 120 次移动、动画、高亮、OLE 及源文件删除回执 |
| `IconTest` | 默认图标、相对/显式资源、降级与 Axolotl 回归 |

`Test` 包含前四项，GitHub CI 执行此入口。其他窗口检查需要交互桌面。测试数据使用独立目录，不移动真实桌面文件；可选 Axolotl 检查只读访问本机入口。

管理面板回归覆盖 24 项后台收纳、期间修改尺寸并保存、同名冲突后重试，以及收纳未完成时请求退出。OLE 检查确认排队期间回执不会要求 Shell 删除源文件。

## 本机结果

2026-11-09，Release 构建为 0 错误、0 警告，上表检查通过。基础拖放、动画、托盘和 Win+D 也已在开发机进行人工确认。

30 秒隐藏管理面板的隔离测试宿主，使用 2 个抽屉和 18 个样例入口，共 6 个采样：

| 指标 | 观测值 |
| --- | --- |
| 归一进程 CPU | 约 0.03–2.21% |
| 工作集 | 约 197.6–205.7 MB |
| 私有内存 | 约 156.9–166.2 MB |
| 120 次移动的位图重建 | 0 次 |
| 移动 API 调用 P95 | 约 0.85 ms |

这些数值属于本机短时测试。宿主包含此前界面测试的资源，不代表发行程序的空闲占用；API 耗时不代表屏幕端到端帧率。

## 性能口径

`logs/performance-current.json` 每 15 秒覆盖写入，最多保存 240 个样本，包含进程 CPU、工作集、私有内存、UI 调度超时、面板可见/交互状态，以及图标和窗口计数。不自动上传。

- CPU = 进程 CPU 时间增量 ÷ 采样墙钟时间 ÷ 逻辑处理器数。
- 首次就绪 = 管理窗口开始构造到所有抽屉首次连接，可能包含样例生成，不是进程冷启动或所有图标完成时间。
- UI 调度超时包含系统调度、休眠和负载影响，不是单独的动画帧率。
- 图标耗时从请求排队到完成，包含等待；共享缓存最多 256 项。
