# 验证说明

当前测试版为 0.1.0-beta.9。功能实现、自动回归和真实系统验收分别记录，避免将模拟通过理解为所有电脑上已稳定。

beta.9 的稳定性修改、可重复的实机操作步骤与记录表见[稳定性验收](stability-validation.md)。

## 自动与隔离检查

| 入口 | 覆盖 |
| --- | --- |
| `SelfTest` | 数据位置、原子保存、兼容迁移、重解析点、冲突和中断 |
| `StorageTest` | 收纳/同步/归还、完整副本确认、下载来源流和拖出解除分组 |
| `LayoutTest` | 抽屉所有权、移除归档、DPI、吸附、尺寸与可见工作区 |
| `P0Test` | 后台 STA、串行顺序、图标请求合并/容量、恢复退避、布局合并和采样 |
| `ManagerTest` | 真实 WPF 配隔离样例：搜索、内容、批量收纳、恢复中心与退出 |
| `ResidentTest` | 托盘与环境消息、20 次隔离宿主销毁/重建 |
| `StorageRenderTest` | 120 次移动、动画、高亮、OLE 及源文件删除回执 |
| `IconTest` | 默认图标、相对/显式资源、降级与 Axolotl 回归 |

`Test` 包含前四项，GitHub CI 执行此入口。其他窗口检查需要交互桌面。测试数据使用独立目录，不移动真实桌面文件；可选 Axolotl 检查只读访问本机入口。

管理面板回归覆盖 24 项后台收纳、期间修改尺寸并保存、同名冲突后重试，以及收纳未完成时请求退出。OLE 检查确认排队期间回执不会要求 Shell 删除源文件。

`StorageRenderTest` 增加悬停抽屉的边框调整回归：在样例窗口开始调整后触发鼠标离开，确认不折叠且宽高仍可修改；松开或鼠标捕获丢失后退出调整状态，按实际光标位置恢复悬停，并重新监听离开。该用例已在修复前复现失败、修复后通过，不移动用户光标。

右下角回归从可见斜线的 12 DIP 内缩位置按下，验证同时调整宽高且锁定后拒绝调整。管理器回归补充：参数按字段选择、取消与空选择、多目标应用、保存后重载、保持独立布局与内容、忙碌时拒绝同步；图标右键命中、悬停保持、锁定与托盘隐藏状态下可用、忙碌时禁用文件操作、单项归还及旧菜单重复操作保护。右键归还仅使用隔离样例；打开外部程序、Explorer 和系统属性窗口仍需发行候选版人工确认。

## 本机结果

2026-11-10，beta.9 Release 构建为 0 错误、0 警告：基础四组共 125 项断言、管理器 71 项、托盘与常驻 53 项、图标 3 项和原生抽屉渲染回归通过。安装器的本机隔离验收另记录 23 项，详见稳定性验收。菜单的普通、焦点、禁用和长名称截图均已检查。

以下性能数值来自 2026-11-09 的早期短时隔离测试，保留测量口径，不作为 beta.9 发行 EXE 的实机性能结果。基础拖放、动画、托盘和 Win+D 曾在开发机人工确认；待验收的真实系统场景仍保持未勾选。

30 秒隐藏管理面板的隔离测试宿主，使用 2 个抽屉和 18 个样例入口，共 6 个采样：

| 指标 | 观测值 |
| --- | --- |
| 归一进程 CPU | 约 0.03–2.21% |
| 工作集 | 约 197.6–205.7 MB |
| 私有内存 | 约 156.9–166.2 MB |
| 120 次移动的位图重建 | 0 次 |
| 移动 API 调用 P95 | 约 0.85 ms |

这些数值属于本机短时测试。宿主包含此前界面测试的资源，不代表发行程序的空闲占用；API 耗时不代表屏幕端到端帧率。

## 性能口径

`logs/performance-current.json` 每 15 秒覆盖写入，最多保存 240 个样本，包含进程 CPU、工作集、私有内存、UI 调度超时、面板可见/交互状态，以及图标和窗口计数。不自动上传。

`Session` 累计区保留本次运行的开始时间、运行时长、总采样数、截至最近采样的平均 CPU、采样观测内存峰值和相对初始基线的内存变化。超过一小时后，累计区继续保留早期基线，明细仍只有最近 240 项；重启进程后重新累计。平均 CPU 根据累计 CPU 时间和观测时间计算，不对各次百分比作简单平均。内存差值包含正常缓存与界面初始化，不能单凭上涨判定泄漏。

`logs/desktop-lifetime.json` 在后台写入，包含触发原因、是否等待恢复、环境错误和显示器信息。日志写入失败会显示状态信息，不中断桌面连接；积压时只保留待写的最新快照。

- CPU = 进程 CPU 时间增量 ÷ 采样墙钟时间 ÷ 逻辑处理器数。
- 首次就绪 = 管理窗口开始构造到所有抽屉首次连接，可能包含样例生成，不是进程冷启动或所有图标完成时间。
- UI 调度超时包含系统调度、休眠和负载影响，不是单独的动画帧率。
- 图标耗时从请求排队到完成，包含等待；共享缓存最多 256 项。
