# 产品规格

栖格的目标是让桌面文件、文件夹和快捷方式按用途形成抽屉，也可映射真实目录，同时保持移动、展开与日常打开操作顺畅。下面分别列出已经开放的行为和后续产品规则。

## v1.0.0 范围确认

2026-11-18 用户要求首个正式版完成基本功能：普通多类型文件/文件夹、真实文件夹映射、基础文件动作、排序/多选与跨抽屉，并具备匹配的安全操作、备份和卸载恢复能力。v1.0.0 已接入基本文件能力，验收进度见下方清单。最低行为和边界见[v1.0.0 基本功能清单](v1-basic-features.md)，版本顺序见[更新计划](release-plan.md)。

## 当前能力

| 项目 | 当前行为 |
| --- | --- |
| 环境 | Windows 11 x64 |
| 内容 | 个人桌面根目录的普通文件、文件夹和快捷方式，另支持外部引用及目录映射 |
| 抽屉 | 多个，分别命名、移动、缩放、滚动、折叠与锁定 |
| 布局 | 屏幕/相邻抽屉边缘及中心吸附，Alt 绕过，分别记忆 |
| 文件 | 实际收纳，退出归还，单项拖出解除分组 |
| 同步 | 同路径快捷方式身份核对、更新与历史保留 |
| 管理 | 空间沙盘、工作台详情、属性检查器、运行与恢复 |
| 常驻 | 托盘、单实例唤回、可选登录启动 |
| 分发 | 自带运行时的安装包和便携 ZIP |

桌面整理抽屉的实物收纳范围为个人桌面根目录，外部项目可添加引用或映射目录。

## 共同交互

单击选中、双击打开，鼠标悬停提供反馈。标题拖动整组移动，边缘调整大小；图标按可用宽度排布，超出滚动。

折叠保留标题，可选择常开、悬停或手动模式；标题按钮和双击标题开合：悬停模式不改变模式，临时折叠保持至鼠标离开，下次移入继续展开；持续手动模式由设置显式选择。悬停立即开始约 150 ms 的展开/收起动画。底部空间不足时向上展开并保留标题位置。拖入折叠标题时展开，文件拖入或菜单交互中保持可操作。关闭管理面板保持常驻；完全退出等待文件操作及归还。

吸附只作用于当前操作的抽屉，不推动其他抽屉或重排系统图标。临时多屏回收保留首选布局，主动调整则保存新布局。

## 功能入口规则

标题“···”与标题右键提供抽屉设置：展开方式、图标间距、锁定和同步；图标右键提供该项的打开、位置、属性与归还；内容空白处右键提供新建网址、添加/粘贴桌面快捷方式、打开当前抽屉目录/终端、刷新和管理内容。工作台把添加、新建与刷新放在内容标题下，失效记录提供行内清理；全局设置仍由面板底部入口打开。

沙盘卡片双击进入指向抽屉的工作台并清除旧搜索，空白处双击不跳转。菜单使用统一的线条图标、分组、悬停与键盘焦点样式，适用目录和内容类型用实际名称说明；尚未支持的文件操作不伪装为可用能力。

## v1.0.0 两类抽屉的操作规则

以下属于**规划规格**。当前仅实现桌面快捷方式整理，不能据此将映射或普通文件描述为已可用。

| 类型 | 内容来源 | 退出 | 移除抽屉 |
| --- | --- | --- | --- |
| 桌面整理抽屉 | 桌面内容实际收纳；其他位置按引用处理 | 已收纳内容归还原位 | 先归还，引用只解除关联 |
| 文件夹映射抽屉 | 直接读取真实文件夹 | 文件留在文件夹 | 只移除视图与关联 |

两类共用布局、折叠、滚动和吸附，区别由文件来源及操作语义决定。

### 桌面整理的扩展

- 从个人桌面拖入普通文件或文件夹时实际收纳，归还按原路径处理。
- 从其他位置拖入时保留原文件并建立引用，清楚标识来源；引用失效提供重新定位、打开位置和移除关联。
- 文件夹条目可选择在抽屉内二级浏览或用资源管理器打开。
- 自动同步仅用于可靠识别的快捷方式；普通文件不能仅按同名自动合并。
- 移除抽屉前完成实际内容归还。引用移除不删除原件。
- 拖回桌面解除该项分组，下一次启动不重新收纳。

### 文件夹映射

选择「文件夹映射抽屉」后，可在目录选择器中选择已有目录或新建文件夹。确认目录后再创建抽屉。

- 映射直接展示文件夹的当前内容，外部增删改后刷新，不导入一份托管副本。
- 默认显示直接子项；子文件夹可二级浏览或由资源管理器打开。
- 拖入/拖出沿用资源管理器的同盘移动、跨盘复制及 Ctrl/Shift 语义，反馈真实操作。
- 删除内容进入回收站；不支持回收站时提示并保留，不静默改为永久删除。
- 移除映射或退出不删除、搬走目标目录及内容，即便目录由栖格创建。
- 离线、改名或权限不足时保留关联，支持重新定位，不自动重建空目录代替原目录。
- 创建目录成功、保存映射失败时保留目录，允许用户重新选择。

## 文件操作约束

普通文件与目录需要独立操作层，覆盖进度、取消、跨盘、目录树、占用、空间不足、冲突和中断。不能直接去掉现有快捷方式大小限制代替实现。

已确认副本、元数据、目录逐项状态及恢复依据应足以解释每次删除源文件的原因。符号链接、目录联接、云占位文件和系统对象需要明确支持范围。

跨抽屉拖放区分改分组与真实移动/复制：两个整理抽屉可优先改成员归属，涉及映射目录则可能构成真实文件操作。具体规则随对应文件层验收后开放。

## 外观与扩展

2026-11-20 更新：下一轮优先推进外观和主题，并行建立性能基线。新能力的交付顺序和验收要求见[开发计划](roadmap.md)。

- 主题首批为“素简”（现有简洁风格重新打磨）和“雾映”（Win11 原生毛玻璃风格）。每套均支持亮色（白色）、暗色（黑色）和跟随系统；主题与明暗模式独立选择并保存，覆盖管理面板、桌面抽屉、右键菜单及二级窗口。
- “雾映”强调背景模糊、半透明底色、细边框和克制阴影，文字与图标保持清晰。系统材质或兼容模拟需实测选型；关闭透明效果、材质不可用及游戏/低内存模式时可降级同主题底色，基本操作保持可用。
- 每个抽屉可隐藏整个标题栏并回收其空间，保留名称和内容归属，形成可自由排布的纯净容器。隐藏后以 Alt+拖动空白处移动；边缘缩放、锁定和吸附继续有效，右键空白及管理面板可恢复标题。首版隐藏标题时保持展开，保留原展开偏好；合并抽屉保留菜单切换成员入口。
- 提供“贴屏边角使用直角”开关：只取消接触屏幕外侧可用边界的对应圆角，朝桌面内部的角继续采用主题圆角；移开即恢复。考虑任务栏与 DPI，显示器接缝或只贴邻近抽屉不触发。
- 当前开发版已开放按抽屉保存的背景透明度（0–80%，默认 12%），标题菜单、标题右键和管理面板参数区可调，支持选择同步；图标和文字保持不透明，菜单逐层减少透明度并加深底色。颜色、圆角、标题和图标尺寸等其他受控选项分批开放；不复制成员或几何布局，不引入任意脚本或第三方主题执行环境。

## 卡片抽屉

卡片默认不出现在桌面，由用户主动添加。首版一抽屉一张卡，复用抽屉的位置、吸附、锁定、隐藏标题、主题和贴边直角。音乐卡先行，展示系统媒体会话可提供的封面、歌名、进度和播放控制。后续依次安排时钟／日历、天气和系统状态卡。

画面静止时停止连续绘制。音乐卡仅在可见且播放时旋转唱片。暂停、隐藏、完全遮挡或启用游戏和低内存模式时停止动画，保留基本信息和可用操作。其他卡片按数据变化或低频周期更新。

## 前瞻试用版之后

- **多抽屉标签页**。将两个或更多抽屉合到一个桌面窗口，每个抽屉对应一个可切换的标签页。保存组关系、标签顺序和当前页，允许拆回独立抽屉。切换和拆分保留文件归属、内容及排序，隐藏标题时从菜单切换。
- **按规则自动归位**。用户可按类型、扩展名或名称关键词指定目标整理抽屉，并调整匹配优先级。默认关闭，首版在用户确认预览后处理个人桌面新增内容。冲突或目标不可用时保留原件，记录结果并支持归还。

## 备份与迁移

自动备份覆盖配置、成员、实际托管文件和文件夹及历史副本，提供保留策略、失败反馈和恢复验证。当前仅支持原数据目录恢复，正文上限 512 MB、20000 个文件。外部映射目录默认只保存关联，不自动复制全部外部内容。

开发顺序和实机验收见[开发计划](roadmap.md)。
