# 产品规格

栖格的目标是让桌面快捷方式按用途形成抽屉，同时保持移动、展开与日常启动操作顺畅。下面分别列出已经开放的行为和后续产品规则。

## 当前能力

| 项目 | 当前行为 |
| --- | --- |
| 环境 | Windows 11 x64 |
| 内容 | 个人桌面根目录的 .lnk / .url，每个不超过 4 MB |
| 抽屉 | 多个，分别命名、移动、缩放、滚动、折叠与锁定 |
| 布局 | 屏幕/相邻抽屉边缘及中心吸附，Alt 绕过，分别记忆 |
| 文件 | 实际收纳，退出归还，单项拖出解除分组 |
| 同步 | 同路径快捷方式身份核对、更新与历史保留 |
| 管理 | 空间沙盘、工作台详情、属性检查器、运行与恢复 |
| 常驻 | 托盘、单实例唤回、可选登录启动 |
| 分发 | 自带运行时的安装包和便携 ZIP |

当前不收纳普通文件/文件夹，不接收其他位置的引用，不支持公共桌面入口。映射类型尚未开放创建。

## 共同交互

单击选中、双击打开，鼠标悬停提供反馈。标题拖动整组移动，边缘调整大小；图标按可用宽度排布，超出滚动。

折叠保留标题，悬停立即开始约 150 ms 的展开/收起动画。拖入折叠标题时展开，文件拖入或菜单交互中保持可操作。关闭管理面板保持常驻；完全退出等待文件操作及归还。

吸附只作用于当前操作的抽屉，不推动其他抽屉或重排系统图标。临时多屏回收保留首选布局，主动调整则保存新布局。

## 两类抽屉的后续规则

以下属于**规划规格**。当前仅实现桌面快捷方式整理，不能据此将映射或普通文件描述为已可用。

| 类型 | 内容来源 | 退出 | 移除抽屉 |
| --- | --- | --- | --- |
| 桌面整理抽屉 | 桌面内容实际收纳；其他位置按引用处理 | 已收纳内容归还原位 | 先归还，引用只解除关联 |
| 文件夹映射抽屉 | 直接读取真实文件夹 | 文件留在文件夹 | 只移除视图与关联 |

两类共用布局、折叠、滚动和吸附，区别由文件来源及操作语义决定。

### 桌面整理的扩展

- 从个人桌面拖入普通文件或文件夹时实际收纳，归还按原路径处理。
- 从其他位置拖入时保留原文件并建立引用，清楚标识来源；引用失效提供重新定位、打开位置和移除关联。
- 文件夹条目可选择在抽屉内二级浏览或用资源管理器打开。
- 自动同步仅用于可靠识别的快捷方式；普通文件不能仅按同名自动合并。
- 移除抽屉前完成实际内容归还。引用移除不删除原件。
- 拖回桌面解除该项分组，下一次启动不重新收纳。

### 文件夹映射

创建支持“选择已有文件夹”和“创建文件夹并映射”。新建默认位于 `QigeData/Folders`，允许另选位置；重名提示，不合并、不覆盖。

- 映射直接展示文件夹的当前内容，外部增删改后刷新，不导入一份托管副本。
- 默认显示直接子项；子文件夹可二级浏览或由资源管理器打开。
- 拖入/拖出沿用资源管理器的同盘移动、跨盘复制及 Ctrl/Shift 语义，反馈真实操作。
- 删除内容进入回收站；不支持回收站时提示并保留，不静默改为永久删除。
- 移除映射或退出不删除、搬走目标目录及内容，即便目录由栖格创建。
- 离线、改名或权限不足时保留关联，支持重新定位，不自动重建空目录代替原目录。
- 创建目录成功、保存映射失败时保留目录，允许用户重新选择。

## 文件操作约束

普通文件与目录需要独立操作层，覆盖进度、取消、跨盘、目录树、占用、空间不足、冲突和中断。不能直接去掉现有快捷方式大小限制代替实现。

已确认副本、元数据、目录逐项状态及恢复依据应足以解释每次删除源文件的原因。符号链接、目录联接、云占位文件和系统对象需要明确支持范围。

跨抽屉拖放区分改分组与真实移动/复制：两个整理抽屉可优先改成员归属，涉及映射目录则可能构成真实文件操作。具体规则随对应文件层验收后开放。

## 外观与扩展

有限样式定制列为下一轮 P1，分批支持颜色、透明度、圆角、标题和图标尺寸等受控选项，并复用参数选择同步；不承诺任意脚本或主题执行环境。

## 已记录的备份与迁移需求

自动备份与恢复列为 P0，范围包含配置、成员与栖格实际托管快捷方式的一致快照，提供保留策略、失败反馈和恢复验证。外部映射目录默认只保存关联，不自动复制全部外部内容。

Pogget 个人迁移分析列为 P1，可先交付一次性迁移工具或操作，不要求成为通用产品功能。开始分析时需向用户索取指定的两个目录，再确认可转换字段、内容类型与未支持项。具体资料清单和边界见[备份与 Pogget 迁移计划](backup-migration-plan.md)。两项均未实现。

开发顺序和实机验收见[开发计划](roadmap.md)。
