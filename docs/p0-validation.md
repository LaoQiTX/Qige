# beta.8：三个 P0 的实现与验收

本轮实现桌面环境恢复、集中恢复入口、后台任务与性能记录。仍为测试版；没有将模拟检查当作真实硬件或长时间验收。

## 桌面生命周期与多屏

- Explorer 桌面宿主失效后重建原生窗口、OLE 拖放注册和托盘；不因重新连接而搬移文件或重新分组。
- 显示设置、DPI、解锁和恢复供电消息合并 300 ms 后处理；2 秒看门狗兜底检查。连接失败按 1、2、4、8、16、30 秒安排下次尝试，由看门狗触发，不持续高速重试。
- 拖动期间推迟环境重排；桌面窗口销毁时取消旧手势。自动回收位置与尺寸不写成用户的首选布局，接回显示器后可按原设置恢复；用户主动修改布局会保存新设置。
- 目录监听出错或环境恢复时重建监听；每约 30 秒安排完整同步，补偿睡眠和缓冲区溢出导致的丢失事件。

## 运行与恢复

管理面板底栏、托盘均有入口。列出待完成阶段、同名不同目标、重复入口、丢失文件和未完成的抽屉移除；展示桌面与收纳两处完整路径。

可打开位置、重新检查、重试归还或同步，也可将收纳副本另存到 `QigeData/recovery/exports/<id>`。导出不覆盖目标，校验 SHA256，保留命名数据流（包括下载来源），不移除原件或分组记录。

冲突时不会提供强制覆盖按钮。用户先检查并移开或改名冲突文件，再重试。找不到文件时保留记录，不宣称能够找回已经被外部删除的字节。

退出会先等待文件操作，再逐组后台归还；任一组失败会保留程序、文件与恢复入口。关机/注销尽力归还，但 Windows 强制终止或断电仍需下次从原目录恢复。

## 性能与后台工作

- 文件操作使用独立 STA 串行队列，沿用校验复制、记录持久化后删源的协议。UI 读取稳定快照，后台结果发布时合并用户期间修改的位置、尺寸、折叠与锁定；跨抽屉预约防止并发重复收纳。
- 图标解析使用另一条后台 STA 队列，界面先显示内容占位；管理面板与抽屉共用至多 256 项的 FIFO 缓存，并合并相同图标的并发请求。失效的异步结果不会应用到新的分组状态。
- 拖动继续使用缓存位图与原生窗口移动；移动不重新解析图标或移动系统桌面图标。
- 每 15 秒记录进程 CPU、工作集、私有内存、UI 定时调度超时、面板显示/交互状态；最多 240 个样本，覆盖写入本机 `logs/performance-current.json`。另外记录图标加载次数、缓存命中、排队到完成的耗时和窗口绘制/重建次数。
- CPU 是进程 CPU 增量除以采样墙钟时间和逻辑处理器数。首次就绪时间从管理窗口开始构造计至所有抽屉首次连接，包含样例生成时的开销，不等于冷启动或首次图标全部加载时间。UI 超时包含系统调度、休眠与重负载影响，不是单独的帧率指标。
- 正常后台采样没有上传或自动联网；日志含本机路径，分享前应脱敏。恢复副本和历史版本不会被自动删除。

## 回归入口与实机边界

`build.ps1 -Task Test -Configuration Release` 包含数据、迁移、收纳、多抽屉、布局以及新增 `P0Test`。`P0Test` 检查重试调度、后台 STA、缓存合并与容量、失败后继续执行、布局合并、冲突保留、导出来源流和采样上限。

交互测试在已登录桌面运行：

- `ManagerTest`：真实 WPF 管理界面配隔离样例；验证后台批量收纳、期间布局修改、恢复中心的重试、退出等待与冲突取消；输出常规及最小尺寸预览，并记录 30 秒隐藏管理窗口的进程基线。该基线运行在测试宿主中，不作为发行 EXE 的冷启动或长期内存结论。
- `ResidentTest`：20 次销毁/重建隔离桌面宿主，检查折叠、OLE、成员及文件哈希；消息模拟显示变化、唤醒、解锁及任务栏重建。不重启真实 Explorer、不切换显示器、不更改真实启动项。
- `StorageRenderTest`：120 次窗口移动、位图重建计数、移动 API 耗时、动画、高亮和真实 OLE 数据对象。
- `IconTest`：图标来源与 Axolotl 回归。

待人工验收：实际 Explorer 重启、睡眠/唤醒、显示器拔插/接回、混合缩放切换、登录启动，以及与 Wallpaper Engine/Pogget 共存的长时间运行。代码已提供自动恢复和本机观测手段，这些场景尚不能标记为完整通过。

## 本轮本机结果（2026-11-09）

Release 构建为 0 错误、0 警告。数据/存储/布局/P0、管理面板、托盘与隔离宿主恢复、绘制/OLE、图标检查通过。管理面板验证了 24 项后台收纳期间修改宽度并持久化、冲突重试，以及尚有收纳任务时退出并归还。OLE 补充检查确认后台排队时 `Performed DropEffect=0`，源文件保留，由本程序完成校验搬移。

30 秒隐藏管理面板的隔离测试宿主（2 个抽屉、18 个样例入口），6 个采样的归一进程 CPU 约 0.03–2.21%，工作集约 197.6–205.7 MB，私有内存约 156.9–166.2 MB；属于测试宿主短时观测，包含此前界面回归留下的进程资源，不代表发行程序启动后空闲占用。最后一轮 120 次移动没有重建图标位图，移动 API 调用耗时 P95 约 0.85 ms；这不等于端到端显示帧率。
