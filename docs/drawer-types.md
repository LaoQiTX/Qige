# 抽屉产品规格：桌面整理与文件夹映射

状态：beta.3 已完成多个桌面整理抽屉、尺寸、滚动、吸附和管理面板；类型模型已预留文件夹映射。映射抽屉、普通文件／文件夹和外部引用尚未实现。
本规格记录最新产品决定；历史文档中“只有一种分区”等描述不再代表后续范围。

## 两种抽屉

| 类型 | 用途 | 内容来源 | 退出程序 |
| --- | --- | --- | --- |
| 桌面整理抽屉 | 整理真实桌面上的内容 | 桌面文件实际收纳到应用数据目录；其他位置保持既定的引用语义 | 已实际收纳的内容归还原桌面路径，分组记忆保留 |
| 文件夹映射抽屉 | 在桌面展示一个真实文件夹的内容 | 直接读取指定文件夹，不导入既有文件、不复制一份到抽屉存储 | 文件保留在对应文件夹，映射和布局设置保留 |

两类共用桌面融合、移动、调整尺寸、折叠动画、悬停反馈、滚动、位置吸附、边缘与中心对齐、布局记忆。以类型区分内容来源和文件操作，不以“是否折叠”区分类型。

### 桌面整理抽屉

- 延续已确认的实际收纳方案，扩展支持普通文件和文件夹，不限于 .lnk / .url。
- 从个人桌面拖入时实际收纳；正常退出或“归还桌面”恢复原路径。
- 将图标拖回桌面解除分组；下次启动不重新收纳该项。
- 从其他位置拖入仍按此前决定只建立引用，保留原文件，不自动将其搬入应用存储；引用需要清晰标识。
- 引用失效时显示状态，提供重新定位、打开所在位置和移除引用。移除引用不删除原文件；拖出引用的具体交互后续定义，不照搬“归还桌面”。
- 实际收纳的文件夹仍是一个文件夹条目，按既定设置选择二级浏览或资源管理器打开；它与新建一个持续映射的抽屉是不同操作。
- 自动吸收桌面重建快捷方式只用于可可靠识别的快捷方式；普通文件同名出现时不能依照名称自动合并或覆盖。
- 删除抽屉需要先完成已收纳内容的归还；遇到冲突保留抽屉及恢复依据。移除引用仅移除关联。

### 文件夹映射抽屉

创建入口有两种：

1. **选择已有文件夹**：选择真实目录，在桌面创建展示其内容的抽屉；创建映射本身不改变文件。
2. **创建文件夹并映射**：填写文件夹名、确定位置，创建真实目录后建立映射。目录创建失败时不创建失效抽屉；映射配置保存失败时保留已创建目录，允许重新选择，不自动删除。

已确认：默认在 QigeData/Folders 下创建真实文件夹，同时允许用户选择其他位置。重名时提示另取名称，不合并或覆盖已有目录。若用户希望展示已有目录，使用“选择已有文件夹”。

- 抽屉显示目标文件夹当前内容，外部新增、删除、重命名后同步刷新。
- 目标目录是该抽屉内容的实际存放位置；QigeData 仅保存映射、布局和必要缓存，不另外托管目标目录已有内容。
- 默认展示直接子项；双击文件打开，子文件夹按设置进入二级浏览或资源管理器，内部浏览有返回及路径提示。
- 对内容进行实际移动、复制、重命名或删除时，作用于映射目录中的真实对象。引用在此目录中的 .lnk 仍是正常文件，不能当作另一套隐式引用列表。
- 已确认：拖入沿用资源管理器规则，同盘默认移动、跨盘默认复制；支持常见修饰键（Ctrl 复制、Shift 移动），拖放反馈明确显示实际操作。文件夹内部的循环移动、移动到自身等无效操作需要拒绝。
- 已确认：删除内容进入回收站。目标位置不支持回收站时，提示原因并保留文件，不静默改成永久删除。此操作与“移除映射”分别命名。
- 拖出到桌面按资源管理器规则对真实文件执行移动／复制操作，给出对应拖放反馈；它不使用桌面整理抽屉的“归还原位”逻辑。
- **移除映射／删除抽屉仅移除视图和关联**，文件夹及其中内容保留；即使目标文件夹由栖格创建，也不随抽屉移除而删除。
- 正常退出不把映射内容搬到桌面。下次启动从同一路径读取并恢复抽屉。
- 外置盘离线、路径被改名或权限不足时保留映射，显示不可用并支持重新定位；不重建空文件夹覆盖用户意图，也不从配置抹掉成员。
- 用户显式选择的已有文件夹、新建文件夹位置和主动文件操作可在安装目录之外；程序自身配置、恢复记录、缓存仍集中在 QigeData。

## 文件操作保护

这是从快捷方式原型扩展为文件整理工具的必要工作：

- 现有 VerifiedTransfer 仅面向小型快捷方式，不能直接移除大小限制后用于普通文件和目录。
- 设计独立的普通文件／目录操作层，支持进度、取消、占用、同名冲突、磁盘空间不足和失败恢复。
- 大文件与目录操作不阻塞桌面拖动、动画、托盘；取消或中断保留源、已确认内容及可解释的恢复状态。
- 同盘与跨盘分别实现并验证；不覆盖同名文件，不把未确认复制视为可删除源的依据。
- 目录需要逐项记录和恢复，保留必要元数据；符号链接、目录联接、云占位文件、系统对象等单独验证支持范围，不能盲目递归或悄悄转换。
- 程序运行期间被打开或修改的已收纳文件，退出时需要在文件稳定且可操作后归还；原路径同名冲突不覆盖，向用户显示待处理内容。
- 分区间拖动区分两类内容所有权。两个整理抽屉间优先改变分组；涉及映射目录时可能构成真实文件移动／复制，不能只修改成员记录。详细跨类型拖放规则在文件操作方案中确认。
- 现有 beta 数据迁移必须保留入口身份、分组、历史版本和恢复语义。

## 开发顺序

1. 多抽屉基础与类型模型：基础和类型配置已完成；当前创建入口仅开放桌面整理，映射类型的创建和菜单随功能实现。
2. 多分区、调整大小、滚动、边缘／中心吸附与布局记忆：beta.3 已实现。
3. 已有文件夹映射：显示、打开、刷新、重新定位、移除映射；这些操作不搬移文件。
4. 创建文件夹映射及资源管理器规则的移动、复制和回收站删除。
5. 普通文件／文件夹的安全收纳与退出归还，通过恢复验证后开放。

普通文件支持已经纳入正式需求。以上排序用于控制实现和验收依赖，不把它移出范围。有限样式定制继续暂缓。

## 验收要点

- 从创建入口能区分整理桌面和映射目录；两类折叠、布局交互一致。
- 映射已有目录不改变文件，移除抽屉或退出不删除／搬出目录内容。
- 外部改动能刷新；目录不可用保留映射，恢复可访问后重新显示。
- 普通文件与目录可以收纳、归还，关闭托盘控制窗不触发归还；真正退出按记录完成。
- 大文件、中文、跨盘、目录树、同名冲突、占用、取消和中断均有明确结果，文件内容不丢失。
- 现有快捷方式更新同步和图标解析继续工作，不将普通文件误认作更新入口。
- 双屏缩放、折叠与布局变化不改变文件来源和操作含义。
