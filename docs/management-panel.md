# 抽屉管理面板

管理面板按照 `docs/原型设计/qige_management_panel.html` 实现，沿用 WPF / Win32 技术栈。

## 界面与操作

- 顶部统一标题栏包含栖格标志、真实桌面连接状态、空间沙盘 / 工作台详情切换、新建抽屉及窗口控制。
- 默认进入空间沙盘：点阵背景、双列抽屉卡片、真实快捷方式图标预览、显示器筛选。卡片中的定位与归还按钮作用于对应抽屉。
- 工作台详情左侧按抽屉类型分组并显示实际数量，提供带图标的搜索框、两行抽屉说明、圆角白色选中项和蓝色状态点，偏好设置固定在底部。文件夹映射尚未支持时明确显示 0 和说明。抽屉名称或入口名称均可搜索，无匹配结果时显示空状态；内容列表支持打开和单项归还。
- 两种模式共用当前选择与右侧属性检查器，提供重命名、网格 / 列表内容透视、常驻 / 悬停展开、锁定、全局吸附、显示器切换及位置和尺寸编辑。
- 显示器、位置与尺寸默认折叠，展开后仍提供真实桌面坐标预览；显示器变化时刷新选择列表。锁定后禁止修改布局。
- 新建抽屉使用居中模态弹窗，名称无效时就地反馈。文件夹映射按原型保留说明，但当前后端仅支持桌面快捷方式整理，因此明确标记为尚未提供。
- 偏好设置连接已有登录启动功能。原型中的桌面双击隐藏与全屏自动隐藏尚无后端实现，界面不提供无效开关。
- 正式模式和隔离样例的关闭按钮或 Alt+F4 均提供继续托盘运行和退出归还两种选择。取消或 Escape 关闭弹窗并恢复键盘焦点。

## 视觉与实现

面板使用原型的海渊深藏青 `#0F1D38`、宝石钴蓝 `#2563EB`、白色和冷灰背景，使用 WPF 原生图形重建品牌标志。面板颜色和控件样式限制在窗口资源内，桌面抽屉仍使用原有共享配色。

窗口默认 1200 × 780，最小 1100 × 710。右侧属性与内容预览独立滚动。无新增运行时依赖、浏览器或字体下载。

`StorageWindow.xaml` 定义布局与状态样式，`StorageWindow.Presentation.cs` 负责模式、筛选、内容图标缓存与弹窗交互；抽屉生命周期和原有文件恢复流程仍由 `StorageWindow.cs` 与 `ShortcutStore` 承担。

## 文件归还

整抽屉归还保留分组记忆，单项归还会解除该入口的分组。解除抽屉前确认归还；出现同名冲突时保留磁盘文件和恢复记录。退出归还未完成时取消关闭、展示错误并保持面板可访问。

## 验证

使用 `pwsh -NoProfile -File scripts/build.ps1 -Task ManagerTest` 运行隔离样例检查，并导出沙盘、工作台、最小窗口和新建弹窗截图。覆盖选择同步、模式切换、搜索与无结果、真实图标、预览切换、显示器筛选、单项归还冲突与重试，以及原有批量收纳、创建、移除、锁定、折叠和退出归还。

`-Task Test` 运行文件安全、收纳与布局回归。跨显示器移动的鼠标体验、多屏插拔及混合 DPI 显示仍需实机核对。
