# 开发计划

当前可用范围见[使用指南](user-guide.md)。本页列出后续顺序，勾选项代表实现已接入，不代表所有实机场景完成验收。

## 下一轮版本与优先级

2026-11-18 更新：`1.0.0` 为首个正式版，系统验收继续跟踪。下一正式版 `1.1.0` 聚焦内存/CPU、游戏模式、动态调节及包体优化。每个正式版之前继续用对应 beta，不切回 alpha，不为新增计划单独发版。版本顺序、可行性、测量依据与验收条件见[正式版与测试版更新计划](release-plan.md)。

每完成一个可发布的新版本，默认同步提交并推送 GitHub 代码、版本配置和文档，更新对应 GitHub Release，上传安装包、便携包及 SHA256，并确认 CI、标签、提交和附件一致。此约定持续适用，不必每个版本重新询问是否推送；未完成的日常修改不等同于发布新版本。执行细则见[开发说明](development.md#版本与推送约定)。

按顺序执行：继续跟踪 1.0.0 实机验证，推进下一轮试用版和 1.1.0 性能主线；每次完成一项再开始下一项。下表 P0 属于发布门槛；其余旧 P1/P2/P3 是后备需求，不能越过新版本主线自动展开。

| 优先级 | 内容 | 顺序与依赖 |
| --- | --- | --- |
| 必需 · 1.0.0 | 多类型内容、文件夹映射 | 先内容模型与映射只读展示，再普通文件/目录的事务操作层和收纳 |
| 必需 · 1.0.0 | 基础文件操作、排序多选、跨抽屉 | 剪贴板、新建、重命名、回收站、保存顺序及批量，依赖安全文件层 |
| P0 · 1.0.0 | 升级、备份、卸载和稳定性收口 | 普通文件纳入恢复与容量策略，再启动、异常卸载、系统和长时间验收 |
| 优先 · v1.0.0 后的下一轮试用版 | 合并抽屉，点击标题切换内容 | 保留成员各自的内容和文件归属，排在普通交互待办之前 |
| P1 · 1.1.0 | 内存/CPU 优化、游戏模式、动态调节、包体 | 在新版文件能力基线上测量，再逐项优化和验收 |
| 已接入 · 持续扩展 | 自动备份与恢复 | beta.11 仅含快捷方式版本，扩展至普通内容后重新验收，性能模式不得削弱事务安全 |
| 已接入 · 后续扩展 | 抽屉“···”二级设置菜单 | 已有展开、锁定、图标密度和同步入口；样式扩展后续排期 |
| 后备 P1 | 有限样式定制及选择同步 | 亮色/暗色/系统、颜色、透明度、圆角、标题栏和图标尺寸，单独排期 |
| P3 · 10 | 多抽屉对齐、等间距分布 | 属于布局效率增强 |
| P3 · 11 | 完整 Explorer 扩展右键菜单 | 当前常用菜单继续使用；以后补全 Shell 扩展与菜单生命周期 |
| P3 · 12 | 双击桌面空白隐藏/显示 | 在桌面共存、事件命中与多屏行为稳定后处理 |
| P3 · 13 | 单 EXE 便携分发评估 | 不阻塞安装包与文件夹式便携版交付 |

当前执行顺序以[版本更新计划](release-plan.md#版本顺序)及[v1.0.0 基本功能清单](v1-basic-features.md)为准：基础模型 → 映射 → 通用文件事务 → 收纳与操作 → 排序多选 → 备份/卸载/实机验收，每次完成一项。v1.0.0 之后再进入 v1.1.0 性能主线。

自动备份范围、恢复约束及验收要求见[备份与恢复计划](backup-migration-plan.md)。

- [ ] 合并两个已有抽屉后，桌面上显示一个抽屉。标题栏同时显示两个原抽屉的名称，点击标题只显示对应抽屉的内容，并标出当前选中的标题。
- [ ] 每个抽屉保留自己的名称、内容和排序。右键文件操作与拖放作用于当前选中的抽屉。

## 后续版本 · 管理面板设计与交互

本轮 v1.0.0 优先完成第 6 项新建类型卡切换，并完善桌面抽屉右键文件操作、标题计数位置和工作台内容列表的滚轮滚动。

剩余界面待办按下表从上到下推进。P1 先解决操作一致性与导航问题，P2 再增加布局能力和动效，P3 在赞助地址确定后接入。现有 v1.1.0 性能主线保留独立排期。

### 两种视图的建议

- **首次打开时进入工作台详情。** 左侧找抽屉，中间浏览、搜索、排序和批量整理，右侧编辑抽屉属性。适合知道目标、要连续操作文件的场景。
- **空间沙盘用于浏览全部抽屉及内容。** 卡片按桌面空间展示，单击选中，双击在沙盘内展开该抽屉的完整内容，供打开和执行该抽屉的常用操作。关闭内容面板回到沙盘原位置。两种视图各自保存搜索和滚动状态，共用内容与文件操作逻辑。
- **将视图切换收成标题栏右侧的「视图」菜单。** 菜单标出当前视图，保持一次点击可发现，并记住上次所用的视图。先验证切换可发现性和沙盘内双击是否满足用户任务，再确定内容面板的最终形态。

## 优先：完成日常使用验收

- [ ] 性能监测与优化排查：分别采样管理面板显示/隐藏、抽屉空闲/悬停/滚动及不同抽屉和图标数量下的 CPU、工作集、私有内存、UI 延迟与句柄；建立预热后的基线和至少一小时趋势，再按分配/堆与原生资源证据定位优化点。优先分析内存组成、位图/界面资源生命周期及周期刷新和重复分配，不凭短时上涨判定泄漏。

2026-11-16 只读查看运行中的 beta.13：约 13.5 分钟、54 个已有样本，会话平均 CPU 约 0.23%（按全部逻辑处理器归一化），最近工作集约 469 MiB、私有内存约 373 MiB；当时管理面板显示，1 个抽屉、图标缓存 4 项。内存值得优先排查，但启动早期基线尚未加载完整界面，不能用其差值证明泄漏。本轮仅记录初步观察，后续单独完成受控采样和瓶颈定位。

- [ ] 真实 Explorer 重启、锁屏/解锁、休眠/唤醒后恢复。
- [ ] 显示器断开与接回、负坐标、混合 DPI 及缩放切换。
- [ ] 实际登录启动、盘符延迟可用、托盘恢复。
- [ ] 与 Wallpaper Engine、其他桌面工具共存的长时间运行。
- [ ] 干净 Windows 环境安装、原目录升级、卸载保留和重装。
- [ ] 发行 EXE 冷启动、空闲与操作期 CPU/内存、持续运行增长。

用现有日志记录复现条件与结果，不以模拟消息和短时测试替代实机验收。详见[验证说明](validation.md)。

稳定性收尾的源码修改与逐项操作、记录格式见[稳定性验收](stability-validation.md)。尚未完成实机操作的条目继续保持未勾选。

## 有限样式定制

颜色、透明度、圆角、标题栏、图标尺寸等受控定制列为 P1，分批实现，不等待完整普通文件层。当前不引入任意 CSS、脚本或第三方主题执行机制。

- [ ] 配色模式支持“亮色（白色） / 暗色（黑色） / 跟随系统”，可在设置中主动选择并保存；覆盖管理面板、抽屉与右键菜单。选择跟随系统时响应 Windows 主题变化，手动选择时保持用户设置。

样式参数开放后，接入现有“同步到全部抽屉”，允许勾选同步范围，不复制抽屉内容或几何布局。
