# 开发计划

当前可用范围见[使用指南](user-guide.md)。本页列出后续顺序，勾选项代表实现已接入，不代表所有实机场景完成验收。

## 下一轮版本与优先级

2026-11-10 用户确认：后续继续 beta，不切回 alpha。当前版本为 `0.1.0-beta.10`；常规修复和增量功能继续递增 beta 编号，形成较大功能阶段时可调整为 `0.2.0-beta.1`，具体按实际范围选择。新增待办本身不触发版本号变更。

每完成一个可发布的新版本，默认同步提交并推送 GitHub 代码、版本配置和文档，更新对应 GitHub Release，上传安装包、便携包及 SHA256，并确认 CI、标签、提交和附件一致。此约定持续适用，不必每个版本重新询问是否推送；未完成的日常修改不等同于发布新版本。执行细则见[开发说明](development.md#版本与推送约定)。

以下优先级取代本页原先仅按章节排列的先后顺序。P0 优先保障数据与可恢复性，P1 为下一轮核心能力，P2/P3 为后续增强；不要求一个 beta 版本实现所有条目。

| 优先级 | 内容 | 顺序与依赖 |
| --- | --- | --- |
| P0 · 1 | 自动备份与恢复 | 先保护配置、抽屉归属和托管快捷方式；导入、数据格式迁移等操作前建立可恢复快照 |
| P0 · 2 | 现有功能稳定性验收及问题修复 | 系统恢复、多屏/DPI、真实启动、长时间共存及干净系统安装；与功能开发并行，稳定版发布前必须完成 |
| P1 · 3 | 抽屉“···”二级设置菜单 | 承载当前抽屉的展开、锁定与后续样式设置，复用现有属性后端 |
| P1 · 4 | 有限样式定制及选择同步 | 先颜色、透明度、圆角、标题栏，再图标尺寸；统一接入“同步到全部抽屉” |
| P1 · 5 | Pogget 个人迁移分析与一次导入 | 分析阶段向用户索取指定两个目录；优先满足个人迁移，不强制开发成通用产品功能 |
| P1 · 6 | 已有文件夹映射 | 先直接子项只读展示、打开、刷新及失效重定位；作为更广内容导入的前置能力 |
| P2 · 7 | 组内排序、框选多选及批量操作 | 先排序与选择，再按已支持内容提供批量动作 |
| P2 · 8 | 普通文件/目录及映射文件操作 | 需要进度、取消、冲突、跨盘、占用、中断恢复和回收站支持；不能复用快捷方式搬移假装完成 |
| P2 · 9 | 跨抽屉拖放 | 先快捷方式改分组；涉及映射目录或普通文件时依赖对应文件层 |
| P3 · 10 | 多抽屉对齐、等间距分布 | 属于布局效率增强 |
| P3 · 11 | 完整 Explorer 扩展右键菜单 | 当前常用菜单继续使用；以后补全 Shell 扩展与菜单生命周期 |
| P3 · 12 | 双击桌面空白隐藏/显示 | 在桌面共存、事件命中与多屏行为稳定后处理 |
| P3 · 13 | 单 EXE 便携分发评估 | 不阻塞安装包与文件夹式便携版交付 |

建议接下来的 beta 分批完成自动备份与恢复、抽屉菜单及第一批样式；Pogget 结构分析可同时进行。映射和普通文件按依赖逐步加入后续 beta。若个人迁移需要未支持类型，先生成报告并保留原件，等待相应能力后再导入。

自动备份范围、恢复约束，以及 Pogget 分析时必须索取的目录，见[备份与 Pogget 迁移计划](backup-migration-plan.md)。两项目前均为已记录需求，尚未实现。

## 优先：完成日常使用验收

- [ ] 真实 Explorer 重启、锁屏/解锁、休眠/唤醒后恢复。
- [ ] 显示器断开与接回、负坐标、混合 DPI 及缩放切换。
- [ ] 实际登录启动、盘符延迟可用、托盘恢复。
- [ ] 与 Wallpaper Engine、其他桌面工具共存的长时间运行。
- [ ] 干净 Windows 环境安装、原目录升级、卸载保留和重装。
- [ ] 发行 EXE 冷启动、空闲与操作期 CPU/内存、持续运行增长。

用现有日志记录复现条件与结果，不以模拟消息和短时测试替代实机验收。详见[验证说明](validation.md)。

稳定性收尾的源码修改与逐项操作、记录格式见[稳定性验收](stability-validation.md)。尚未完成实机操作的条目继续保持未勾选。

最小正式版的范围、剩余门槛与当前证据见[正式版就绪评估](release-readiness.md)。

## 已有文件夹映射

- [ ] 创建与桌面整理清晰区分的抽屉类型。
- [ ] 选择已有目录，显示、打开并刷新直接子项。
- [ ] 目录不可用时保留关联，支持重新定位。
- [ ] 移除映射只解除视图，不删除目录或内容。

先完成只读展示与刷新，再开放真实文件操作。

## 文件操作与普通文件

- [ ] 创建文件夹并映射，默认 `QigeData/Folders`，允许另选位置。
- [ ] 映射抽屉的同盘移动、跨盘复制、修饰键和回收站删除。
- [ ] 普通文件/目录的进度、取消、冲突、占用及中断恢复。
- [ ] 桌面普通内容的安全收纳、退出归还和其他位置引用。
- [ ] 子文件夹二级浏览或资源管理器打开。
- [ ] 跨抽屉拖放，明确成员变更和实际文件操作的区别。

已确认语义集中在[产品规格](product-spec.md)，验收通过后逐项开放。

## 体验增强

- [ ] 抽屉标题“···”打开当前抽屉的二级菜单，集中提供样式与功能设置；替换当前直接打开管理面板的行为。右键标题也可打开同一菜单，图标间距设置放在该菜单内。
- [ ] 抽屉支持手动展开与折叠，可点击按钮或双击折叠抽屉切换状态。
- [ ] 折叠抽屉拖到屏幕底部后，若下方可用高度不足以容纳完整展开高度，自动改为从下向上展开。
- [ ] 缩小抽屉内图标的横向间隔，改善相同宽度下的容纳数量；以其他工具同宽可放 5～6 个图标为体验参照，提供“紧凑 / 标准 / 宽松”布局密度选项。
- [ ] 右键抽屉空白处提供“在当前目录打开命令行”“新建文件”“打开目录”等操作；依赖抽屉目录映射与对应文件操作能力，明确当前目录归属后接入。
- [ ] 管理面板底部持续展示当前应用版本号。
- [ ] 组内排序、框选多选、批量操作。
- [ ] 完整 Explorer 原生右键扩展菜单；当前已有应用内单项菜单及系统属性入口。
- [ ] 多抽屉批量对齐与等间距分布。
- [ ] 双击桌面空白隐藏/显示抽屉和系统桌面图标。
- [ ] 评估单 EXE 的解包位置、启动与升级约束。

## 有限样式定制

颜色、透明度、圆角、标题栏、图标尺寸等受控定制列为 P1，分批实现，不等待完整普通文件层。当前不引入任意 CSS、脚本或第三方主题执行机制。

样式参数开放后，接入现有“同步到全部抽屉”，允许勾选同步范围，不复制抽屉内容或几何布局。
