# 开发计划

当前可用范围见[使用指南](user-guide.md)。本页列出后续顺序，勾选项代表实现已接入，不代表所有实机场景完成验收。

## 当前基础

- [x] 多抽屉、自由布局、尺寸调整、滚动、折叠与悬停动画。
- [x] 屏幕/相邻抽屉的边缘与中心吸附、辅助线、Alt 绕过。
- [x] 管理面板、托盘、可选登录启动及单实例唤回。
- [x] 桌面快捷方式收纳、更新同步、归还与冲突保护。
- [x] 环境恢复调度、监听重建和低频完整同步。
- [x] 运行与恢复面板、退出等待、冲突重试与校验导出。
- [x] 后台文件操作、图标缓存与本机性能记录。
- [x] 自带运行时的中文安装包和便携 ZIP。

## 优先：完成日常使用验收

- [ ] 真实 Explorer 重启、锁屏/解锁、休眠/唤醒后恢复。
- [ ] 显示器断开与接回、负坐标、混合 DPI 及缩放切换。
- [ ] 实际登录启动、盘符延迟可用、托盘恢复。
- [ ] 与 Wallpaper Engine、其他桌面工具共存的长时间运行。
- [ ] 干净 Windows 环境安装、原目录升级、卸载保留和重装。
- [ ] 发行 EXE 冷启动、空闲与操作期 CPU/内存、持续运行增长。

用现有日志记录复现条件与结果，不以模拟消息和短时测试替代实机验收。详见[验证说明](validation.md)。

## 下一阶段：已有文件夹映射

- [ ] 创建与桌面整理清晰区分的抽屉类型。
- [ ] 选择已有目录，显示、打开并刷新直接子项。
- [ ] 目录不可用时保留关联，支持重新定位。
- [ ] 移除映射只解除视图，不删除目录或内容。

先完成只读展示与刷新，再开放真实文件操作。

## 随后：文件操作与普通文件

- [ ] 创建文件夹并映射，默认 `QigeData/Folders`，允许另选位置。
- [ ] 映射抽屉的同盘移动、跨盘复制、修饰键和回收站删除。
- [ ] 普通文件/目录的进度、取消、冲突、占用及中断恢复。
- [ ] 桌面普通内容的安全收纳、退出归还和其他位置引用。
- [ ] 子文件夹二级浏览或资源管理器打开。
- [ ] 跨抽屉拖放，明确成员变更和实际文件操作的区别。

已确认语义集中在[产品规格](product-spec.md)，验收通过后逐项开放。

## 体验增强

- [ ] 组内排序、框选多选、批量操作。
- [ ] 原生右键菜单。
- [ ] 多抽屉批量对齐与等间距分布。
- [ ] 双击桌面空白隐藏/显示抽屉和系统桌面图标。
- [ ] 评估单 EXE 的解包位置、启动与升级约束。

## 暂缓：有限样式定制

保留颜色、透明度、圆角、标题栏、图标尺寸等受控定制方向。先稳定桌面交互和文件层，再确定选项范围；当前不引入任意 CSS、脚本或第三方主题执行机制。
