# 后续开发规划

本文件记录已完成的阶段与后续范围。当前功能以使用说明为准。

## 产品范围：两类抽屉

最新决定见 [抽屉产品规格](drawer-types.md)：

- **桌面整理抽屉**：延续桌面实际收纳与退出归还，扩展支持普通文件和文件夹；其他位置的文件保留既定引用语义。
- **文件夹映射抽屉**：直接展示真实目录，支持选择已有文件夹或创建新文件夹后映射；退出不搬走内容，移除映射不删除文件夹。
- 两类共用移动、折叠、尺寸、滚动、吸附及对齐；文件来源与操作语义清晰区分。
- 新建文件夹默认放在 QigeData/Folders，可另选位置；映射抽屉沿用资源管理器同盘移动／跨盘复制、删除进回收站的规则。

### 位置吸附与对齐

| 参考对象 | 对齐方式 |
| --- | --- |
| 当前显示器工作区 | 左、右、上、下边缘；水平及垂直中心线 |
| 同一显示器上的其他分区 | 左右边缘、上下边缘、水平中心线、垂直中心线 |
| 分区排列 | 后续补充相邻分区等间距辅助 |

已实现的交互：

- 拖动靠近参考线时轻度吸附，并显示细辅助线；可同时对齐两个方向。
- 全局设置可以关闭吸附；按住 Alt 临时绕过。
- 进入 10 DIP、脱离 18 DIP，避免边缘来回跳动和粘住拖不走；手感仍需实机微调。
- 多条参考线竞争时优先选择距离最近的一条，拖动期间保持稳定，辅助线与实际落点一致。
- 按当前显示器工作区计算，避开任务栏；跨屏拖动按所在屏幕处理，并适配不同缩放和负坐标。
- 调整大小时同样支持边缘对齐，并遵守分区最小尺寸；中心线主要用于移动定位。
- 折叠分区按可见标题条参与边缘及中心对齐，展开动画不触发额外吸附或挪动其他分区。
- 吸附与对齐只调整当前操作分区；不会推动其他分区或重排系统桌面图标。
- 保存最终位置与尺寸，重启后恢复；屏幕断开后的回收仍遵循可见工作区约束。

等间距、多分区批量对齐和分布属于后续增强，不强制一次完成。

## 暂缓：有限样式定制

用户希望支持一定范围内的自定义样式，本轮暂缓实施。后续讨论颜色、透明度、圆角、标题栏和图标尺寸等受控选项及其边界；当前不承诺任意 CSS、脚本或第三方主题系统。数据结构与界面实现避免将所有外观参数散落硬编码，待布局稳定后再确定正式样式规格。

## 已纳入范围：映射与普通文件

- 在多抽屉基础上先实现已有文件夹映射的展示、刷新、打开、重新定位和移除关联。
- 创建文件夹映射，以及按资源管理器规则移动、复制和回收站删除真实文件。
- 整理抽屉支持普通文件／文件夹，需要先完成适合大文件、目录、跨盘、冲突和中断的文件操作与恢复层。
- 分区间拖放按两类抽屉的内容来源明确区分，避免将实际文件操作误作单纯改分组。

目标：用户无需手动管理散落的运行库文件。后续至少提供安装包或单 exe 便携版中的一种，具体优先路线在发布验证后确定；当前文件夹式便携包仍可用于开发测试。

- [ ] 评估安装包：允许选择可写的安装目录，提供应用快捷方式、版本升级与卸载入口。
- [ ] 评估单 exe 便携版：无需另装 .NET，确认首次及后续启动速度，并将可控解包／临时文件保留在所选软件目录内。
- [ ] 两种路线都延续 exe 旁的 QigeData 数据约定；单 exe 指程序分发文件，运行时仍会生成数据目录。
- [ ] 升级保留配置、收纳内容、映射关系和恢复依据；卸载默认保留用户数据，不删除映射的真实文件夹。
- [ ] 在干净 Windows 环境验证启动、图标、托盘、开机启动路径、升级及数据恢复，通过后再确定正式分发方式。
