# 开发计划

源码复核日期：2026-11-19；需求与优先级更新：**2026-11-21**。上次核对的源码版本为 **1.0.2**，首个正式版为 1.0.0；版本依据见[工程配置](../src/DesktopGroups/DesktopGroups.csproj)和[更新记录](../CHANGELOG.md)。2026-11-20 已补充现有浅色抽屉美化及渲染回归记录，其余完成状态沿用上次核对。

实现状态依据上次源码、回归用例和验收记录核对。**已实现**表示能力已接入；**部分实现**表示仍有明确缺口；**待实机验收**表示需要真实系统操作的证据。自动或隔离检查不代替实机验收。当前可用范围见[使用指南](user-guide.md)。

待办按 **01–51** 编号追踪。当前先做性能专项，再安排外观和前瞻功能。数据安全与启动是发布门槛，系统兼容与长时趋势集中验收。

## 当前首要任务 · 性能优化（03 → 10 → 11）

1. **测出可复现的常驻内存基线（03）。** 固定版本、数据集和 DPI，分别测无抽屉、全部折叠、展开，以及管理面板打开与关闭后的占用。记录私有工作集、私有提交量和空闲 CPU，单独记录反复展开／折叠的峰值及操作延迟。
2. **定位占用来源（10）。** 对比运行时和后台服务、管理面板生命周期、抽屉位图、提交缓冲与图标缓存的开销，按实际占用排序。
3. **优先修复收益最大的开销（11）。** 用同一场景复测常驻内存、切换峰值、CPU 和操作响应。先交付能复测出收益的优化，再推进材质打磨、额外动效和卡片。

2026-11-21 同机短时采样的私有工作集约为栖格 209 MiB、DeskBox 121 MiB、PecoFence（含守护进程）3.8 MiB。各应用当时的抽屉和内容状态不同，读数用于确定优先级。正式内存目标在受控基线完成后确定。

## 开发待办 · 外观、主题与性能（01–11）

云母和亚克力各提供亮色、暗色、跟随系统三种配色。材质追加和卡片在首轮性能优化验收后安排，使用同一基线复测。

- [x] **01 · 已实现：整理并落地统一设计规范。** 共用色板与控件样式覆盖管理面板、抽屉菜单和文件名弹窗，规范字号及间距，并约定悬停、选中、键盘焦点、禁用和错误状态。布局输入错误在字段旁显示。组合回归覆盖最小窗口及 150%／200% 的 WPF 布局模拟。见[统一控件规范](design.md#统一控件规范)。

- [x] **02 · 已实现：命名主题体系与独立明暗模式。** 「设置 → 外观」提供云母、亚克力及各自的亮暗预览。主题与亮色、暗色、跟随系统偏好分别保存，切换即时应用到桌面抽屉、管理面板、应用内菜单和二级窗口。手动配色保持优先，原有抽屉透明度和菜单深度继续生效。

- [ ] **03 · 部分实现：完善性能采样并建立受控基线。** 已有每 15 秒采样、最近 240 项明细和整次会话累计统计。待补齐低开销的托管堆/分配/GC、GDI/USER/总句柄、线程、磁盘读写和表面重建计数等必要证据；固定数据集并预热十分钟，区分面板显示/隐藏、抽屉空闲/悬停/滚动及不同抽屉和图标数量，建立至少一小时趋势。昂贵诊断仅在排查时启用。先完成当前版本基线，并用同一台机器、同一数据集和操作脚本验证优化收益。

- [ ] **04 · 部分实现：亚克力与云母材质打磨。** 支持系统材质时，管理面板使用原生 Acrylic 或 Mica。桌面抽屉共用低分辨率的模糊壁纸缓存，亚克力保留更多环境色并叠加细纹理，云母使用更浓的底色。系统关闭透明效果时使用同主题的实色背景。待完成多屏壁纸和资源模式的实机对比。

- [ ] **05 · 待开发：隐藏标题的纯净抽屉与自由排布。** 每个抽屉提供“显示标题栏”开关，关闭时隐藏名称、整条标题背景、分隔线及常驻标题按钮，并收回占用空间，只保留内容容器；名称和文件归属仍保留。桌面任意位置移动、边缘缩放、吸附及锁定继续可用：以 Alt+拖动内容空白处移动整个抽屉，避免与图标排序和后续框选混淆；右键空白处及管理面板始终提供抽屉设置和恢复标题入口，满格时也能从管理面板恢复/定位。纯净模式首版保持内容展开，保存此前展开方式，恢复标题后可恢复该方式；不留下看不见的折叠条。合并抽屉隐藏标题时仍可通过菜单切换成员或恢复标题；重启保存设置与桌面布局。

- [ ] **06 · 待开发：贴屏边角取消对应圆角的细节开关。** 增加“贴屏边角使用直角”，可关闭并按抽屉保存。开启后，仅把实际紧贴当前显示器桌面可用区域边界的对应角置为直角：贴左边处理左上/左下，贴上边处理左上/右上，贴左上角时两组取并集，其他方向类推；朝桌面内部的角保留主题圆角。以吸附后的实际位置、DPI 容差和可用区域判定，考虑任务栏占位，不把两个显示器之间的接缝当作外侧屏幕边界；只贴另一个抽屉时不触发。拖离边缘或关闭开关后恢复主题圆角；同步更新背景、边框、裁剪与命中，验证缩放、折叠/向上展开和隐藏标题时的状态。

- [ ] **07 · 部分实现：有限样式定制。** 背景透明度已开放 0–80%（默认 12%），标题“⋯”、标题右键、管理面板参数区均可调整，按抽屉保存并实时预览；菜单每层透明度减半、底色略微加深，图标和文字保持清晰。颜色、圆角、标题栏和图标尺寸仍待开放，使用受控参数；与主题、隐藏标题及贴屏直角设置共同生效，不互相覆盖；已有图标间距密度不等于图标尺寸定制。不引入任意 CSS、脚本或第三方主题执行机制。

- [ ] **08 · 部分实现：扩展外观设置的选择同步。** 当前展开方式、锁定、密度和背景透明度可按字段同步到全部抽屉；主题风格、明暗模式、颜色/圆角/图标尺寸、显示标题栏和贴屏直角开放后加入可勾选同步范围，不复制成员内容或几何布局。未勾选字段保留每个抽屉的独立设置，重启后结果一致。

- [ ] **09 · 待验收：主题与纯净布局组合回归。** 验证“云母/亚克力 × 亮色/暗色/跟随系统”，覆盖浅深与复杂壁纸、常用 DPI、菜单/弹窗、文字对比、系统配色实时切换、手动偏好保存、标题显示/隐藏、屏幕四边四角及多屏。核对纯净抽屉移动/缩放/锁定/恢复入口、贴边与移开后的局部圆角。记录毛玻璃前后资源与响应变化，验证关闭透明效果及游戏/低内存降级不影响打开、排序、拖放和文件操作。

- [ ] **10 · 待优化：依据测量定位内存与 CPU 开销。** 在 03 的基线上分析托管堆、原生资源、位图与界面生命周期、周期刷新和重复分配，逐项提供同机同场景前后对比。已有缓存和后台队列继续保留；不预先把候选位置宣布为瓶颈，不用强制 GC 或清空工作集制造下降。

- [ ] **11 · 待优化：隐藏面板刷新与绘制资源复用。** 优化隐藏面板的内容绑定/预览刷新、抽屉表面和像素缓冲复用、无效重绘及轮询/扫描合并。现有抽屉移动不重建位图，但完整 Render 仍生成 RenderTargetBitmap；已有局部优化不能代表本项整体完成。核对原生对象释放与操作延迟。

历史线索：2026-11-16 的 beta.13 会话约 13.5 分钟、54 个样本，平均 CPU 约 0.23%，最近工作集约 469 MiB、私有内存约 373 MiB。当时管理面板可见、有一个抽屉和四项图标缓存。这份数据仅用于确定排查方向。

## 前瞻基础 · 拖拽反馈与手动模式（12–16）

先完成明确的插入反馈和统一动效策略，再交付手动低内存及游戏模式，供主题和卡片复用。拖拽动效参数在实机和两套主题下校准。

- [ ] **12 · 部分实现：清楚、灵动的插入排序反馈。** 当前已有拖动阈值、跟手图标、目标格悬停高亮、Esc 取消，以及松手保存手动顺序。待补齐等格大小的空心占位框和入口短线；跨过相邻格中线后，仅受影响图标平滑让位；边界加入回差，避免轻微晃动反复换位。默认拿起约 1.05 倍、浅阴影，让位约 160 ms，松手归位约 140 ms；不连续弹跳、不加跟手延迟。支持跨行、首尾插入、拖到上下边缘自动滚动及滚动中准确落点；拖拽期间不改变抽屉尺寸。无效目标或 Esc 取消不改顺序；拖到桌面归还和跨抽屉拖放沿用已有有效目标语义，不能一律当作取消。

- [ ] **13 · 待开发：动效策略与无动画基本功能。** 将排序判定、落点提示、提交保存与动画分离，提供统一的关闭非必要动效能力，并遵循系统减少动画设置。游戏/低内存模式接入后关闭缩放、阴影、平滑让位和落下过渡，位置即时更新；保留跟手预览、占位框、插入短线、排序、取消、边缘滚动、跨抽屉及归还能力。复用单个轻量预览，避免整组截图或额外大缓存；切换策略不丢失正在拖动的状态，不依赖动画完成回调才能提交顺序。

- [ ] **14 · 待开发：手动低内存/节能模式。** 提供可保存的模式开关，接入 13 的无动画策略，减少非必要视觉更新、合并刷新、限制可重建缓存，延后可延期的完整扫描与定时备份。继续支持图标打开、排序、拖放、文件操作和手动备份恢复；退出模式后逐步恢复。公开收益与延迟取舍，不承诺未经测量的内存数字。

- [ ] **15 · 待开发：手动游戏模式。** 在设置和托盘提供开关，减少本应用的动画、预览和非必要后台工作，清楚显示状态与原因；退出后恢复。抽屉保持可用时保留无动画拖拽基本功能；被全屏覆盖时可停止相应视觉工作，多屏或 Alt-Tab 后及时恢复。不得通过退出并归还文件模拟游戏模式。

- [ ] **16 · 待验收：模式切换与性能版本回归。** 对比正常、低内存/节能和游戏模式的功能与资源，验证手动进入、退出、状态恢复及全屏/无边框、多屏、Alt-Tab。短时尖峰、持续压力和自动切换留到对应功能开发后验证。收纳、归还、写盘提交、完整性校验、恢复和必要安全备份不得被节能强行中断；保留脏标记并合并补同步。按 27 在验收周集中记录候选版本的长时趋势。

## 卡片抽屉 · 音乐卡前瞻（17–18）

先用音乐卡验证抽屉复用和性能。卡片加入后，与主题、纯净抽屉及手动模式一起纳入前瞻候选版。

- [ ] **17 · 待开发：卡片抽屉基础与性能验收。** 默认不显示卡片，由用户从新建入口主动添加。卡片是抽屉的内容类型，复用位置和尺寸、吸附、锁定、隐藏标题、主题及贴边直角。首版一抽屉一张卡，纵向堆叠后续根据试用反馈评估。静止零帧指画面无变化时不持续生成渲染帧。卡片隐藏或完全遮挡时暂停动画和非必要的视觉更新。游戏、低内存及系统减少动画时显示静态卡面，保留基本信息和可用操作。用 03 的口径对比添加前、可见、隐藏、遮挡及模式切换时的 CPU、内存、绘制次数和操作延迟。

- [ ] **18 · 待开发：音乐卡「正在播放」。** 作为爱发电前瞻版首张卡片。先验证现有 WPF 安装版和便携版能否订阅 Windows 系统媒体会话（GSMTC），按会话和播放状态事件更新封面、歌名与进度，提供播放器支持的上一首、播放/暂停、下一首。可见且播放时按系统时间线本地推算进度并显示旋转唱片，暂停、隐藏、完全遮挡或进入静态模式时停止旋转。无可用会话或缺少字段时显示对应静态状态。视觉上用唱片搭配看板娘主题方向，用于前瞻展示。

- [ ] **21 · 待实机验收：备份与恢复。** 覆盖旧数据和当前数据的正常恢复、校验失败、目标冲突、恢复中断与回滚。用可丢弃的实机数据集比对恢复前后文件、布局、顺序与归属，核对自动轮换和安全快照能保留可恢复副本。

- [ ] **22 · 待实机验收：异常卸载与原路径重装。** 覆盖正常退出、强杀/崩溃、冲突、离线目录、权限失败、静默卸载和原路径重装。核对未归还内容阻止卸载、恢复路径和失败提示，确认配置与内容保留。卸载保护代码已接入，仍缺完整发行场景验收。

- [ ] **23 · 待实机验收：发行 EXE 启动与干净安装升级。** 在干净 Windows 环境验证安装包和解压后的便携包、默认数据目录写入、原目录升级及实际冷启动。已有解压后启动检查；不能沿用“发行 EXE 完全未验证”的旧描述，也不能用此代替隔离系统安装。 每个面向用户的候选包先做安装和冷启动冒烟检查，干净环境的完整安装与升级矩阵集中在候选版验证。

## 验收周 · 系统兼容与长时趋势（24–27）

主题、手动模式和音乐卡形成前瞻候选版后，集中跑一轮系统场景和长时性能。同批归档 Windows 版本、显示器环境、复现步骤、结果和缺口。日常开发继续跑相关回归。

- [ ] **24 · 待实机验收：Explorer 重启恢复。** 实际重启 Explorer，验证抽屉重新附着、托盘恢复、内容和布局不丢失；不以隔离宿主替换或模拟消息代替。

- [ ] **25 · 待实机验收：锁屏、休眠、登录与延迟磁盘。** 覆盖锁屏/解锁、睡眠/唤醒、真实登录启动、盘符延迟可用及托盘唤回；核对恢复时机、失败重试与文件状态。

- [ ] **26 · 待实机验收：多屏、DPI 与文字可读性。** 覆盖显示器断开/接回、负坐标、混合 DPI、缩放切换、默认/最小管理窗口。工作台工具栏已有布局修复和最小宽度检查；仍需验证常用 DPI 下按钮文字、正常/悬停/禁用状态与对比度。

- [ ] **27 · 待实机验收：桌面共存与长时间资源趋势。** 与 Wallpaper Engine、其他桌面工具共存，记录发行 EXE 冷启动、空闲、悬停、滚动、面板开关及至少八小时运行的 CPU、工作集、私有内存、UI 延迟和句柄趋势。保留复现条件，不用短时上涨直接认定泄漏。 前瞻候选版在验收周集中完成长时测量，后续在正式版候选包有影响常驻资源的变化时复测。

每完成一个可发布的新版本，默认同步提交并推送 GitHub 代码、版本配置和文档，更新对应 GitHub Release，上传安装包、便携包及 SHA256，并确认 CI、标签、提交和附件一致。此约定持续适用，不必每个版本重新询问是否推送；日常修改和本次清单整理不等同于发布新版本。细则见[开发说明](development.md#版本与推送约定)。

功能实现、隔离回归和实机验收分开记录。完成上面的未勾选项后，补上实现与验证依据，再移入已实现清单；只完成部分时保留具体缺口。版本范围见[版本更新计划](release-plan.md)，验收原始记录继续在[验证说明](validation.md)和[稳定性验收](stability-validation.md)维护。

本页为复核后的统一待办顺序。其他文档中的历史 beta 范围和早期缺口描述不作为重新开发已实现能力的依据；使用指南描述当前开放行为，遇到差异继续以源码与实际验证结果核对。
