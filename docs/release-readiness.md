# 最小正式版就绪评估

评估日期：2026-11-18。当前测试版为 beta.14，已接入抽屉设置菜单、手动开合、底部向上展开、图标密度、常驻版本号和自动备份恢复；本页记录最小稳定版仍需完成的门槛。

## 当前结论与版本安排

2026-11-18 用户调整范围：v1.0.0 必须包含多类型普通文件/文件夹、文件夹映射和日常整理能力。此前“现有快捷方式功能足够作为首版”的结论不再适用。当前 beta.14 尚缺通用文件模型、文件事务、基础文件动作、排序多选、跨抽屉、扩展备份及异常卸载保护；具体差距见[v1.0.0 基本功能清单](v1-basic-features.md)。

v1.1.0 继续聚焦内存/CPU、游戏模式、动态调节和包体优化；已知数据丢失、启动或资源失控缺陷仍需在首版前解决。完整顺序见[版本更新计划](release-plan.md)。

## 正式版基本范围

Windows 11 x64，包含桌面整理抽屉和真实文件夹映射抽屉；普通文档、图片、音视频、压缩包、程序文件及目录的条目展示和 Windows 关联打开，桌面内容托管、外部引用、基础文件动作、排序/多选和跨抽屉操作。保留现有布局、折叠、吸附、托盘及登录启动；补齐普通内容备份、升级、退出归还、异常卸载和重装保护。

当前仍只支持个人桌面根目录的 .lnk/.url。文件夹映射、普通文件及以上动作在验收前均不得宣传为已支持。既有自动回归记录见[验证说明](validation.md)，不能代替新增文件层的验证。

## 新增内容能力的发布门槛

| 门槛 | 完成依据 |

| 多格式与映射 | 混合类型及目录正确展示/打开，外部变更刷新，离线与重定位，退出/移除不破坏外部目录 |
| 安全文件操作 | 同/跨盘、目录树、取消、同名冲突、占用、权限和空间不足、强杀后恢复，无未确认删源或错误覆盖 |

## 仍需完成的四组门槛

beta.14 修正右键目录与终端定位，管理面板 106 项通过，Release 构建零警告零错误；文件夹与终端的真实外部启动仍需实机确认。

| 门槛 | 剩余工作 | 完成依据 |
| --- | --- | --- |
| 系统环境恢复 | 真正重启 Explorer、锁屏/解锁、睡眠/唤醒、真实登录启动；多屏断开/接回、负坐标和混合 DPI | 按稳定性验收 S1–S5 逐项实测并留存日志；隔离消息测试不能代替 |
| 长时间稳定与性能 | 与壁纸及其他桌面工具共同运行至少 8 小时；发行 EXE 冷启动、CPU/内存与增长记录 | S6、S8 记录同一进程的分阶段资源和异常；30 秒测试宿主采样不能代替 |
| 干净环境分发 | 干净 Windows 安装、原目录升级、正常退出归还、异常退出后卸载保护、原路径重装继续使用 | S7 实测并补强杀/冲突/静默卸载案例；当前卸载器不自行归还文件，已有隔离安装测试仅为前置证据 |
| 发行收口 | 根据以上结果修复问题，再做最终回归，统一正式版本、说明、已知限制、包及 SHA256 | 固定候选版本完成检查后发布；本地验收包不等于正式发行 |

上述功能门槛及这四组系统门槛尚未全部完成。实测前不承诺还差几天，也不把待验收条目标记为通过。详细步骤和记录表见[稳定性验收](stability-validation.md)。

beta.11 已通过基础与备份五组 169 项、管理器 83 项、常驻与托盘 62 项及原生抽屉渲染回归，Release 构建无警告和错误。备份已实际验证创建、完整性、冲突拒绝、恢复后重新加载与中断回滚。既有 beta.9 本机隔离安装验证记录仍保留，但不能代替新版干净 Windows 环境、真实故障及长期运行验收。详细结果见[验证说明](validation.md)。

## 可在最小正式版之后继续

- 颜色、透明度、圆角、图标尺寸等样式，以及对应的选择同步。
- 抽屉内多级目录浏览、文件缩略图预览和自动分类。
- 框选、批量对齐及完整 Explorer 扩展菜单；基本排序和键盘多选已经纳入首版。

图标右键的常用操作已在本轮接入；完整 Explorer 扩展菜单是后续增强。
