# 最小正式版就绪评估

评估日期：2026-11-10。当前测试版为 beta.9，包含统一设置、参数同步、缩放保护和图标右键菜单；本页记录最小稳定版仍需完成的门槛。

## 最小范围

Windows 11 x64，整理个人桌面根目录的 `.lnk`、`.url` 快捷方式。支持多抽屉、拖动与缩放、悬停展开、锁定、参数一次同步、图标右键常用操作、统一设置、托盘、登录启动、文件归还与冲突恢复，以及安装和升级。

上述主流程已经接入。目前主要差距是实机验收及正式打包收口，无法用代码完成比例准确表达。若将文件夹映射、普通文件操作或自由样式也列为正式版必需项，则属于更大的产品范围。

2026-11-10 后续需求增加自动备份与恢复（P0）及 Pogget 个人迁移分析（P1）。自动备份作为下一轮扩展与真实迁移前的数据保护基础，当前尚未实现；beta.9 仍按原有范围描述。用户确认后续继续 beta，每完成可发布版本同步推送 GitHub 并更新 Release。新的开发顺序和后续索取资料见[开发计划](roadmap.md)及[备份与 Pogget 迁移计划](backup-migration-plan.md)。

## 仍需完成的四组门槛

| 门槛 | 剩余工作 | 完成依据 |
| --- | --- | --- |
| 系统环境恢复 | 真正重启 Explorer、锁屏/解锁、睡眠/唤醒、真实登录启动；多屏断开/接回、负坐标和混合 DPI | 按稳定性验收 S1–S5 逐项实测并留存日志；隔离消息测试不能代替 |
| 长时间稳定与性能 | 与壁纸及其他桌面工具共同运行至少 8 小时；发行 EXE 冷启动、CPU/内存与增长记录 | S6、S8 记录同一进程的分阶段资源和异常；30 秒测试宿主采样不能代替 |
| 干净环境分发 | 干净 Windows 安装、原目录升级、卸载保留数据、重装继续使用 | S7 实测；已有本机隔离安装测试仅为前置证据 |
| 发行收口 | 根据以上结果修复问题，再做最终回归，统一正式版本、说明、已知限制、包及 SHA256 | 固定候选版本完成检查后发布；本地验收包不等于正式发行 |

这四组门槛尚未全部完成。实测前不承诺还差几天，也不把待验收条目标记为通过。详细步骤和记录表见[稳定性验收](stability-validation.md)。

本轮已通过基础四组 125 项断言、管理器 71 项检查及原生抽屉渲染回归，Release 构建无警告和错误。管理器检查覆盖多目标参数同步、文件忙碌保护、图标菜单保持展开与单项归还。外部程序打开、Explorer 定位和系统属性窗口仍需候选版人工确认。发布前的 `0.1.0-beta.9-validation.4`、`validation.5` 已核对 SHA256；其中 `validation.4` 完成本机隔离安装、升级、卸载、重装及数据保留的 23 项检查，测试登记已清理。最终发布包统一为 `0.1.0-beta.9`。干净 Windows 环境的 S7 验收仍待完成。

## 可在最小正式版之后继续

- 抽屉标题“···”二级设置菜单，按用户要求后续处理。
- 颜色、透明度、圆角、图标尺寸等样式，以及对应的选择同步。
- 已有文件夹映射、普通文件/目录、跨抽屉拖放。
- 框选多选、批量对齐、排序及完整 Explorer 扩展菜单。

图标右键的常用操作已在本轮接入；完整 Explorer 扩展菜单是后续增强。
