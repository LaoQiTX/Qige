# 最小正式版就绪评估

评估日期：2026-11-16。当前测试版为 beta.14，已接入抽屉设置菜单、手动开合、底部向上展开、图标密度、常驻版本号和自动备份恢复；本页记录最小稳定版仍需完成的门槛。

## 最小范围

Windows 11 x64，整理个人桌面根目录的 `.lnk`、`.url` 快捷方式。支持多抽屉、拖动与缩放、悬停及手动展开、图标密度、锁定、参数一次同步、图标右键常用操作、统一设置、托盘、登录启动、文件归还、冲突恢复、自动备份，以及安装和升级。

上述主流程已经接入。目前主要差距是实机验收及正式打包收口，无法用代码完成比例准确表达。若将文件夹映射、普通文件操作或自由样式也列为正式版必需项，则属于更大的产品范围。

2026-11-10 后续需求增加自动备份与恢复（P0）及 Pogget 个人迁移分析（P1）。自动备份第一批已在 beta.11 实现并完成隔离恢复验证，当前要求原数据目录恢复；Pogget 导入与跨目录快照迁移仍未实现。用户确认后续继续 beta，每完成可发布版本同步推送 GitHub 并更新 Release。新的开发顺序和后续索取资料见[开发计划](roadmap.md)及[备份与 Pogget 迁移计划](backup-migration-plan.md)。

beta.12 修复卸载后缺失入口阻塞退出，增加显式失效记录清理；本轮基础及备份 175 项、管理面板 88 项通过。系统实机、长期运行及干净环境分发门槛继续保持待验收。

beta.13 按操作对象重排抽屉菜单、工作台工具栏与失效清理入口，接入沙盘双击内容编辑，并修复悬停/手动开合兼容性。基础与备份 179 项、管理面板 103 项及原生抽屉渲染通过；完整管理器曾出现一次后台等待超时，后续两轮通过，长期环境验证仍不可省略。

## 仍需完成的四组门槛

beta.14 修正右键目录与终端定位，管理面板 106 项通过，Release 构建零警告零错误；文件夹与终端的真实外部启动仍需实机确认。

| 门槛 | 剩余工作 | 完成依据 |
| --- | --- | --- |
| 系统环境恢复 | 真正重启 Explorer、锁屏/解锁、睡眠/唤醒、真实登录启动；多屏断开/接回、负坐标和混合 DPI | 按稳定性验收 S1–S5 逐项实测并留存日志；隔离消息测试不能代替 |
| 长时间稳定与性能 | 与壁纸及其他桌面工具共同运行至少 8 小时；发行 EXE 冷启动、CPU/内存与增长记录 | S6、S8 记录同一进程的分阶段资源和异常；30 秒测试宿主采样不能代替 |
| 干净环境分发 | 干净 Windows 安装、原目录升级、卸载保留数据、重装继续使用 | S7 实测；已有本机隔离安装测试仅为前置证据 |
| 发行收口 | 根据以上结果修复问题，再做最终回归，统一正式版本、说明、已知限制、包及 SHA256 | 固定候选版本完成检查后发布；本地验收包不等于正式发行 |

这四组门槛尚未全部完成。实测前不承诺还差几天，也不把待验收条目标记为通过。详细步骤和记录表见[稳定性验收](stability-validation.md)。

beta.11 已通过基础与备份五组 169 项、管理器 83 项、常驻与托盘 62 项及原生抽屉渲染回归，Release 构建无警告和错误。备份已实际验证创建、完整性、冲突拒绝、恢复后重新加载与中断回滚。既有 beta.9 本机隔离安装验证记录仍保留，但不能代替新版干净 Windows 环境、真实故障及长期运行验收。详细结果见[验证说明](validation.md)。

## 可在最小正式版之后继续

- 颜色、透明度、圆角、图标尺寸等样式，以及对应的选择同步。
- 已有文件夹映射、普通文件/目录、跨抽屉拖放。
- 框选多选、批量对齐、排序及完整 Explorer 扩展菜单。

图标右键的常用操作已在本轮接入；完整 Explorer 扩展菜单是后续增强。
