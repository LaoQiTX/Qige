避免廉价的关键法则：

绝对不用饱和度 100% 的高亮纯蓝（#0000FF），那会散发工业廉价软件的味道。我们选用带微量青黑调的深海渊蓝作为骨架，配以国际标准克莱因/皇家钴蓝作为灵魂点睛。

与 Windows 11 桌面的契合度：

蓝色与白色是微软 Windows 系统的视觉 DNA。这套配色能自然隐入桌面，不管是作为开机自启常驻工具，还是用于日常分类抽屉，都不会争抢视觉焦点。
