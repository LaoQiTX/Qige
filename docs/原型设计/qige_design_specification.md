# 「栖格 Qige」桌面应用管理面板设计方案

> **产品定位**：Windows 11 个人桌面轻量整理与文件夹映射工具。  
> **设计基调**：白净克制、现代原生、结构透气、高安全感知。

---

## 一、 设计思路与信息组织方式

### 1. 核心心智模型：理清两种抽屉的本质差异

管理面板的设计难点，在于让用户对「桌面整理抽屉」与「文件夹映射抽屉」的**文件归属、生命周期、销毁后果**拥有百分之百的清晰确定感，彻底消除误删文件的心理负担：

| 维度 | 桌面整理抽屉 (Desktop Organizer) | 文件夹映射抽屉 (Folder Mirror) |
| :--- | :--- | :--- |
| **本质定位** | 桌面原生文件的**物理收纳盒** | 硬盘真实目录的**桌面透视窗** |
| **数据源** | 散落在 Windows 桌面的图标与文件 | 本地磁盘（如 `D:\Projects`）或外置硬盘 |
| **退出/关闭工具** | 抽屉暂隐或自动归还，**保留物理坐标记忆** | 视窗关闭，硬盘真实文件夹毫无影响 |
| **移除抽屉动作** | **必须先归还内容**（或解除分组自动放回桌面） | **仅解除桌面展示关联**，绝不删除磁盘文件 |
| **删除内容动作** | 将文件移出抽屉并放回桌面 / 或移至回收站 | 将硬盘里的真实文件移入回收站（需二次警示） |

### 2. 空间布局策略：从「散装设置表单」升级为「双轨工作台」

很多桌面工具的管理面板容易陷入“密密麻麻的配置项表单”。栖格管理面板采用 **「分类导航栏 + 双轨工作台（内容清单 + 属性检查器 Inspector）」**：

```
┌────────────────────────────────────────────────────────────────────────┐
│ 栖格 Qige · 工作台管理       [桌面守护中 · 4个抽屉]       [-] [□] [×] │
├───────────────┬──────────────────────────────────┬─────────────────────┤
│ [+ 新建抽屉]  │ 常用工作台 (整理抽屉)  [在桌面上定位] │ [桌面属性检查器]    │
│ [Q 搜索抽屉]  ├──────────────────────────────────┤ · 展开/悬停收起     │
│               │ 收纳内容列表 (9 项)    [归还内容] │ · 锁定桌面位置      │
│ 桌面整理抽屉  │ ├─ Figma.lnk                     │ · 边缘磁吸/中心吸附 │
│ · 常用工作台  │ ├─ 2026需求排期.xlsx             │ · 显示器与列数      │
│ · 临时便签(!) │ ├─ 概念草图.png                  │                     │
│               │ └─ 临时素材/                     │ [数据安全说明]      │
│ 文件夹映射    │                                  │ 收纳保留原始坐标，  │
│ · 设计资产库  │                                  │ 解除分组不删文件。  │
│ · 备份盘(失效)│                                  │                     │
│               ├──────────────────────────────────┤                     │
│ ⚙️ 全局偏好   │ [重新收纳散落]    [解除分组并归还] │                     │
└───────────────┴──────────────────────────────────┴─────────────────────┘
```

- **左侧导航栏 (Sidebar)**：分流呈现两类抽屉，支持状态指示灯（正常运行、待解决冲突、路径失效红点）、全局设置与日志。
- **中间内容管理区 (Main Work Area)**：直观查看抽屉当前容纳的内容，支持实时排序、添加、单项/批量归还到桌面、打开文件夹。
- **右侧桌面属性检查器 (Desktop Inspector)**：将尺寸、列数、常驻展开/悬停收起、贴边磁吸、位置锁定等桌面级物理参数集中在右侧，随选随改，即时生效。

## 二、 关键操作与交互流程

### 1. 桌面定位与联动（Find on Desktop）
- 用户在管理面板中点击抽屉标题旁的 **「在桌面上定位」**。
- 桌面对应的实体抽屉立刻产生 **高亮脉冲光圈（Pulse Ring）** 并轻微弹跳，同时管理面板底部弹出轻量反馈：“已在主显示器右上角高亮定位「常用工作台」”。
- 解决多显示器、多抽屉场景下“找不到抽屉在桌面哪里”的痛点。

### 2. 展开与收起行为（常驻 vs 悬停）
- **常驻展开 (Always Expanded)**：抽屉像物理网格托盘一样贴在桌面壁纸上，文件始终外露，适合高频使用的常用工具与进行中的任务。
- **悬停展开 / 离开收起 (Hover to Expand / Auto-collapse)**：
  - 平时在桌面上自动收缩为贴边的极简 **细长手柄（Handle Pill）**，宽度仅 4~6px，鼠标掠过时才滑出。
  - 支持在检查器中微调「悬停触发延迟（如 150ms）」，避免鼠标滑过时频繁误触发。

### 3. 安全退出与窗口关闭策略
- **点击面板右上角关闭按钮 `[×]`**：
  - 默认**最小化至 Windows 系统托盘**，桌面上的抽屉继续生效、正常吸附与交互。
  - 用户可在偏好设置中自由配置该默认行为，或勾选“不再询问”。
- **从托盘菜单或设置中「完全退出栖格」**：
  - 明确弹窗提示：“检测到 2 个正在生效的桌面整理抽屉，退出时是否将 12 个文件临时归还至桌面原始位置？[临时归还] [保留抽屉状态并退出]”。

## 三、 两类抽屉的新建、异常与空状态全流程

### 1. 新建抽屉向导（引导式认知建立）
用户点击 `+ 新建抽屉` (Ctrl+N) 时，弹出清晰的 **双核决策弹窗**，用通俗语言界定两种能力：
1. **桌面整理抽屉（收纳桌面图标）**：
   - *文案说明*：“把桌面散乱的快捷方式、文档圈选或收纳进一个自适应格子里。退出或解除时归还图标至原始坐标，绝不丢失。”
   - *初始选项*：直接命名并在桌面空白处生成待放入的空抽屉，或“圈选桌面现有图标一键收纳”。
2. **文件夹映射抽屉（连接真实文件夹）**：
   - *文案说明*：“把已有硬盘文件夹（如项目目录、下载库）或新建文件夹映射为桌面动态视窗。随时同步磁盘变动，解除映射不删物理文件。”
   - *输入项*：选择已有本地目录路径（带“浏览”对话框）或选择“新建专属整理文件夹”。

### 2. 异常与问题状态处理
- **情况 A：文件夹映射目录失效（移动硬盘拔出 / 目录重命名 / 网络路径断开）**
  - **视觉警示**：导航栏与头部展示红白警示标签，状态标为「路径失效 (Path Missing)」。
  - **处理方案**：
    - 方案 1：检测到拔出驱动器，提示“重新连接设备 (E:) 后将自动恢复”；
    - 方案 2：提供一键「重新定位目录...」入口，浏览新路径后无缝重新绑定；
    - 方案 3：提供「安全移除此映射」按钮，明确告知用户“移除视窗绝不会删除磁盘里的任何文件”。
- **情况 B：桌面整理抽屉归还冲突（桌面存在同名文件）**
  - **视觉警示**：条目高亮并带有黄色警示角标「1 项归还冲突」。
  - **处理策略**：
    - 策略 1：`自动重命名并归还`（如生成 `Todo_List (1).txt` 并放回桌面）；
    - 策略 2：`继续保留在抽屉内`，避免覆盖桌面文件。

### 3. 空状态设计 (Empty State)
- 当用户新建了一个抽屉尚未添加文件，或所有文件已被归还至桌面时：
  - 抽屉内展示极简虚线托盘插画与指引：
    > “当前抽屉为空  
    > 可以直接从 Windows 桌面拖拽文件进此抽屉，或点击上方「添加文件」。”

## 四、 视觉设计规范与调色板

- **底色与基底**：`#F4F5F7`（桌面视窗外围） / `#FAFAFB`（管理面板工作区背景） / `#FFFFFF`（卡片与容器表层）。
- **文字与层级**：
  - 主标题与关键操作：`#18181B`（Charcoal Black，克制而锐利）
  - 次级信息与标签：`#6B7280` / `#8C939E`
  - 边框与双层衬垫：`#E5E7EB` / `#F0F1F3`（Hairline Hairline 精细描边）
- **功能强调色（点缀而非大面积铺陈）**：
  - 桌面整理抽屉：柔和藏青/靛蓝 `#4F46E5`（背景 `#EEF2FF`）
  - 文件夹映射抽屉：深空青蓝 `#0284C7`（背景 `#E0F2FE`）
  - 正常运行指示：清爽草木绿 `#22C55E`（背景 `#EBF7EE`）
  - 警示与冲突：琥珀黄 `#D97706`（背景 `#FEF3C7`）
  - 异常与危险操作：绯红 `#DC2626`（背景 `#FEE2E2`）
