# v1.0.0 基本功能清单

复核日期：2026-11-18；当前已发布 `0.1.0-beta.14`。用户明确要求首个正式版完成普通文件、多种格式和文件夹映射，因此本清单取代此前“只收口快捷方式即可正式发布”的范围。以下未勾选项是计划，不代表已实现。按依赖逐项完成，再发布 v1.0.0；性能、游戏模式和动态调节仍由 v1.1.0 集中推进。

## 当前具备与实际缺口

| 基本能力 | 当前情况 | v1.0.0 必须达到 |
| --- | --- | --- |
| 抽屉基础 | 已有多抽屉、命名、位置/尺寸、滚动、折叠/悬停、锁定、密度、吸附和布局保存 | 保留并适配下面两种内容类型；默认/最小窗口和常用 DPI 可读可操作 |
| 多种普通文件及文件夹 | 仅个人桌面根目录 `.lnk/.url`，快捷方式上限 4 MB；不支持普通文件和目录 | 文档、PDF、图片、音视频、压缩包、文本、普通程序文件及文件夹都可作为条目，使用 Windows 图标和关联程序打开；文件夹可用 Explorer 打开 |
| 文件夹映射（链接文件夹） | 只有枚举预留，创建与加载均未开放 | 选择已有目录或新建并映射；展示直接子项，自动/手动刷新，支持改名、离线、权限变化、重新定位；退出/移除只解除视图，不搬走或删除目录 |
| 添加与引用 | 可添加/粘贴个人桌面快捷方式、创建网址 | 桌面普通内容可实际收纳；其他目录条目可建立引用且标明来源；引用移除不删除原件；公共桌面快捷方式以引用方式显示，不要求写入公共桌面 |
| 日常文件操作 | 快捷方式有打开、位置、属性、归还；尚无通用重命名、复制/剪切、回收站删除 | 复制/剪切/粘贴、重命名、新建文件夹/文本/网址、移到回收站、打开位置/终端/属性；按抽屉和条目类型显示适用动作 |
| 整理效率 | 有搜索和密度；缺少用户排序、组内多选及完整跨抽屉操作 | 名称/类型/修改时间/大小排序及升降序、手动顺序保存；Ctrl/Shift/Ctrl+A 多选及批量操作；两个整理抽屉可改分组，涉及映射则按实际文件操作处理 |
| 文件事务与恢复 | 现有校验和恢复专为快捷方式设计 | 目录递归、同/跨盘、进度、取消、同名冲突、占用、空间/权限不足、中断恢复；完成确认后才删源文件；不把取消显示为全部成功 |
| 内容一致性 | 已有快捷方式同步、失效清理和恢复提示 | 普通文件外部修改、移动/删除和映射目录变动可正确刷新；离线保留关联，失效引用可重定位；普通文件不按同名自动合并；无重复收纳 |
| 数据保留和备份 | 已有快捷方式备份，正文上限 512 MB/20000 文件，只能原数据目录恢复；卸载保留数据但不自行归还 | 普通托管文件与目录也进入明确的备份/恢复范围，容量不足提前提示；配置/分组/顺序保存；异常退出后卸载防丢失，原路径重装保留内容；旧 beta 数据可升级 |
| 启动与系统稳定 | 已有托盘/单实例/可选登录启动及恢复逻辑；实机验收未齐 | 发行 EXE 可启动，Explorer 重启、休眠/解锁、多屏/DPI、干净安装升级卸载重装及至少八小时运行验收；已知按钮文字问题修复 |

“多格式”是文件条目支持，不是应用内编辑、解码或预览所有格式。打开动作使用用户安装的关联程序；没有关联或拒绝访问时显示可理解的错误，不自动安装程序。普通文件不能继续套用快捷方式的 4 MB 上限；需按空间与传输能力设计限制并在操作前说明。

符号链接/目录联接、云占位文件、网络目录、系统虚拟对象、权限受限或加密文件要单独定义支持范围。第一版可明确拒绝未验证的对象，不能递归跟随联接、静默下载整个云目录或自动提升权限。未知扩展名的普通本地文件仍可展示和搬移，不依赖扩展名白名单。

## 两种抽屉的基础语义

| 行为 | 桌面整理抽屉 | 文件夹映射抽屉 |
| --- | --- | --- |
| 内容来源 | 个人桌面实际收纳；其他位置建立引用 | 指定真实目录的直接子项 |
| 拖入/拖出 | 收纳、归还或改变引用/分组，明确实际文件结果 | 同盘默认移动、跨盘默认复制，Ctrl/Shift 明确覆盖，并反馈实际结果 |
| 退出/移除 | 托管内容归还原路径，引用只解除关联；冲突不覆盖 | 不移动、不删除映射目录与内容 |
| 删除条目 | “解除分组/归还”“移除引用”“删除实际文件”分开命名 | 删除实际文件进回收站；不能回收时提示并保留，不静默永久删除 |
| 打开目录/终端 | 当前抽屉实际收纳目录 | 映射目录本身；不可用时提示并提供重定位，不创建空目录冒充原目录 |
| 备份 | 覆盖约定范围内实际托管内容和配置，恢复前保护现状 | 默认备份映射关联，不把外部目录全文自动复制；明确告知内容不在该备份内 |

文件夹第一版可双击交给 Explorer，抽屉内多级浏览不作为正式版前置。完整 Explorer 扩展菜单、缩略图预览、自动分类、全局快捷键、自定义皮肤、框选和批量对齐也不必阻塞 v1.0.0。亮色/暗色/跟随系统继续保留待办，不能用视觉主题替代文件能力。

## 推荐实现顺序

1. **基础模型与现有缺陷**：修复文字问题，区分托管文件、引用、映射；统一文件操作接口、所有权/冲突规则，设计旧数据迁移及只读降级；保留现有快捷方式保护。
2. **文件夹映射只读阶段**：创建/选择目录，列出多类型文件，双击打开、定位、刷新、失效重定位和安全移除。先形成可用 beta，尚不声称通用文件操作完成。
3. **普通文件/目录安全操作层**：后台任务、复制/移动、进度/取消、目录树、空间与占用、冲突处理、中断日志及恢复；通过隔离文件/目录场景验证。
4. **桌面收纳与日常操作**：接入普通文件/目录及外部引用，扩展剪贴板、新建、重命名、回收站、跨抽屉改分组与映射文件操作。引用和真实文件操作用不同文案。
5. **排序、多选、搜索一致性**：完成保存顺序、基础快捷键和批量动作，管理面板和桌面抽屉操作结果一致；文件变化不丢选择或产生重复条目。
6. **备份/升级/卸载收口与系统验收**：普通大文件/目录的备份容量策略、旧 beta 升级、断电/强杀后恢复、卸载归还与原路径重装，完成实机和长时间测试，再发布 v1.0.0。

各阶段可拆成多个 `1.0.0-beta.N`，完成一项再推进下一项。阶段范围与编号见[版本更新计划](release-plan.md)，逐项勾选见[开发计划](roadmap.md)。

## 必测的基本场景

- 混合 PDF、Office 文档、图片、视频、压缩包、无扩展名文件、中文/空格名称、空目录、多层目录及大于 4 MB 的普通文件；显示、打开、迁移及归还结果正确。
- 同盘与跨盘、同名文件/目录、源文件仍在写入、只读/占用、目标空间不足；复制未确认不删源，取消/重启后结果可解释，无错误覆盖。
- 映射目录外部增删改、离线/改名/权限变化；重连不丢内容，移除抽屉不删外部目录；引用失效可重新定位或解除。
- Ctrl/Shift 多选、排序后拖放、批量取消/部分失败；重启后分组和顺序保留，跨抽屉无重复所有权。
- 旧 beta 升级保留快捷方式和布局，托管普通文件备份及恢复容量预检，冲突不覆盖；异常退出/卸载/原路径重装不丢文件。
- 新版内容加载后重新执行真实系统恢复、常用 DPI 与长时间资源验收；不能沿用仅快捷方式版的结果宣布文件层稳定。

本次为范围复核，不修改应用版本，不发布空版本，不对用户桌面执行真实文件操作。
