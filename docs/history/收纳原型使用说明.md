# 快捷方式收纳原型

当前是固定单组的小原型，已接入托盘、可选开机启动和桌面窗口恢复。基础常驻交互已通过用户确认；真实 Explorer 重启、休眠与双屏插拔仍待验证。详细范围见《常驻与恢复验证.md》。

## 先看样例

运行 `./build.ps1 -Task Demo`，或在收纳窗口点击“打开样例”。样例包含三个在项目内创建的快捷方式，不移动真实桌面文件。

点击“定位分区”后回到桌面，查看“常用”面板。拖动标题条，所有图标随面板整体移动；双击图标打开入口。右上角“−”折叠为标题条，鼠标移入立即开始展开、离开立即开始收起，过渡约 150 毫秒，不设置悬停等待，中途可反向切换。图标悬停显示柔和高亮，点击选中使用更明显的颜色；移开只取消悬停高亮，不取消选中。

样例关闭时把样例内容归还项目内的样例目录。样例不接收拖入的真实桌面文件。

## 试用真实桌面快捷方式

运行 `./build.ps1 -Task Run` 或直接打开项目内编译后的 DesktopGroups.exe。

1. 在个人桌面选择少量 `.lnk` 或 `.url`。
2. 回到收纳窗口，点击“收纳选中”。快捷方式会实际搬入项目的 `Storage/Default`，面板自行显示内容。公共桌面、普通文件、文件夹和外部目录暂不移动。
3. 点击“定位分区”并回到桌面，拖动标题条。拖动不调用系统图标重排；单击选中、双击打开。
4. 点击“全部归还”可暂停收纳并归还原桌面路径，分组记忆保留；“重新收纳”恢复。关闭真实桌面控制窗口会收起到托盘，分区继续工作；选择“退出并归还”才归还并退出。重新启动会按记忆收纳。
5. 从分区内按住图标拖到桌面空白处松开，归还该快捷方式并解除分组，下次启动不再自动收纳它。拖动时有图标预览，按 Esc 或在其他窗口上松开会取消。样例模式不向真实桌面拖出内容。

固定单组最多 12 项，尚无滚动、调整大小、多组、框选和系统右键菜单。个人桌面的快捷方式可拖到面板或折叠标题：进入时开始展开并显示边框反馈，拖放过程中保持展开，移出后收起。OLE 拖入及此前的即时悬停、高亮和 Axolotl 图标已获用户确认；本轮用户确认动画流畅、拖回桌面正常。“收纳选中”继续可用。拖出当前只支持桌面，不支持拖到其他应用或文件夹。快捷方式归还到原桌面路径，像素位置由 Explorer 安排，尚未按松手位置或记录中的原坐标定位。

图标优先读取快捷方式指定的图标资源；没有指定或资源失效时，从目标程序提取，最后回退到 Shell。相对图标路径按原桌面位置和工作目录解析，搬入 Storage 不改写快捷方式。已用 Axolotl Launcher 的只读副本验证搬移前后图标一致。

## 更新与冲突

监听原桌面路径的重新创建和修改，延迟约 1 秒合并通知，临时占用会有限重试。

- 同路径、同目标、同启动参数及同工作目录：自动接收新入口，刷新分区，并保留旧版本。
- 目标或参数变化、无法解析：保留桌面新入口与分区旧入口，提示检查。
- 改名、带版本号的新目标路径、公共桌面更新：当前不自动推断。

归还时如果原路径存在不同目标内容，不覆盖，会阻止退出并显示控制窗口。可将冲突项改名或移到自己选择的位置，再点击“全部归还”。不要清理项目内的恢复数据。

## 文件与恢复

成员、已解除分组的历史、面板位置和逐项搬移状态位于 `Data/Groups/default.json`。运行内容及旧版本在 `Storage/Default`；旧版本目前不会自动清理。拖回桌面先保存归还意图，完成归还后移出活动成员；中断后继续归还，不因重启重新收纳。

搬移先记录源路径和校验值，再复制并落盘，完整副本确认写入记录后才移除源文件。备用数据流（包括下载来源标记）会保留。同名内容不覆盖，文件占用或复制不完整时保留源文件及记录。

强制退出、断电或系统注销时，无法保证全部内容当场归还；文件可能留在 Storage。下次启动会读记录并继续当前分组，随后可用“全部归还”恢复。尚未验证真实跨盘中断或突然断电，不能把项目内模拟测试当作这些场景已验收。

开机启动默认关闭，可在控制窗口或托盘开启／关闭；开启后登记当前用户注册表的单个启动入口，指向项目内 exe 和根目录，登录后收起到托盘，不在 C 盘安装副本。F 盘在登录时必须可用。重新打开 exe 会唤回已运行的控制窗口，避免启动第二个收纳实例。

Pogget、Wallpaper 保持运行。用户已确认本轮托盘和 Win+D 正常；完整共存、真实 Explorer 重启、休眠与双屏变化仍待验证。分区窗口失效后会重试挂接，显示器变化后重新检查可见位置和缩放。
