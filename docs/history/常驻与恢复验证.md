# 常驻与恢复验证

日期：2026-11-07。当前仍为单分区、最多 12 个个人桌面快捷方式的原型。

## 使用变化

- 关闭真实桌面的控制窗口：收起到托盘，分区继续工作，收纳内容留在项目 Storage。
- 托盘双击：打开控制窗口。右键：打开窗口、找回分区、归还、重新收纳、开机启动、退出并归还。
- 控制窗口的“退出并归还”或托盘的“退出并归还桌面”：归还原路径并退出；冲突或占用导致归还失败时保留程序并显示问题。
- “全部归还”：归还内容但保留分组记忆，暂停当前会话收纳；“重新收纳”恢复。
- 重复打开项目 exe：唤回现有控制窗口，不启动第二个收纳实例。
- 样例模式：关闭窗口仍然退出，只归还项目内的样例，不使用真实桌面收纳。

## 开机启动

默认关闭，可在控制窗口或托盘切换。开启后在当前用户 HKCU\Software\Microsoft\Windows\CurrentVersion\Run 登记一个属于本项目的值，命令指向 F 盘项目中的 exe，并传入项目根目录和 --background。关闭只移除本项目自己的、内容仍匹配的值，不改其他启动项。

程序不复制到 C 盘；配置、存储与缓存继续留在项目中。注册表登记是系统集成信息，Windows 对其存储的写入不受项目数据目录控制。F 盘必须在登录时可用。Windows 启动应用设置中若禁用了入口，还需由用户在系统中重新启用。

真实系统启动项在本轮测试中未改变。开启／关闭的边界通过内存中的注册表替身验证；尚未实际注销或重启验收登录启动。

## 桌面恢复行为

首次启动等待 Explorer 桌面可用，挂接成功后才开始新的收纳。窗口失效或宿主变化时清理旧表面并重新创建，重新登记 OLE 拖入；文件本身和成员不因表面重建搬移。折叠状态保存在成员记录中，重建或再次启动时恢复。

每 2 秒检查句柄和父级，健康时不重建画面、不重排系统图标。Explorer 重建、显示设置变化、解锁与唤醒通知触发合并检查；鼠标操作结束后再处理环境变化。显示器变化时使用实际工作区域找回分区，并按目标屏幕缩放绘制。屏幕之间的空隙不作为可用放置区域。

窗口恢复状态：Data/Diagnostics/desktop-lifetime.json。文件搬移恢复记录：Data/Groups/default.json。不要删除 Data 或 Storage。
