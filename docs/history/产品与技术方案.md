## 2. 文件模型调整

以下为旧路线记录，已被第 10 节的实际收纳决定替代。

用户已选择桌面原文件保持真实路径，工具只分组及管理显示。此前 Storage 搬移、退出搬回的默认路线已取消。外部文件仅引用，文件夹按设置内部浏览或资源管理器打开。

原路径可让安装器继续访问已有快捷方式，但不能保证所有更新器都按原路径写入。必须分别验证原路径覆盖、删除重建、改名、新版本路径和公共桌面新增。

## 3. 桌面融合候选方式

优先复用原生 Shell 图标：通过 ShellWindows 桌面对象查询 IShellBrowser / IFolderView，读取图标位置与身份；用户明确加入测试分区后，调用 SelectAndPositionItems 定位。

分区标题及边框先尝试作为 Explorer 桌面图标宿主的子窗口。测试边框中部挖空，真实图标仍由 Explorer 绘制和接收输入。这是验证方案，不是完整半透明背景实现。

后续实际反馈证实：跨进程挂接的 WPF Window 和 HwndSource 即使返回可见、层级正常，也未形成用户可见的标题与边框。当前改为 Win32/GDI 原生子窗口绘制，不再将 WPF 渲染表面挂入 Explorer。

GDI 初版的分层背景已由用户确认能看到，普通非分层标题／边框仍不可见。修正使标题／边框也使用分层窗口，背景使用鼠标穿透及部分透明，标题边框使用不透明绘制并在中部挖空。用户已确认标题、边框、底色全部可见，随后反馈拖动闪烁。

本轮将拖动与尺寸变更分开：只有尺寸变化才重建区域及字体，移动只对两个已有分层画面调用 DeferWindowPos，保留尺寸与层级，不强制重绘。当前 Explorer 子窗口实测批量定位使用最小 NOSIZE / NOZORDER / NOACTIVATE 标志可用，之前额外标志组合会返回参数错误。鼠标位置合并到调度队列，取消松开后残留的移动回调；图标更新限制为至少间隔 33 毫秒，松开及捕获丢失时补交最终位置。

新增 RenderTest 在实际桌面创建空分区，通过与指针拖动相同的队列连续移动 120 次，检查真实 HWND 坐标和两层对齐。当前结果：移动重绘 0/0、字体与区域重建 0、松开补交通过；测试不移动桌面图标。结果保存于 TestData/NativeRender/results.json。实际鼠标拖动及含图标场景的最终合成闪烁仍需确认，不能以内部检查代替视觉验收。

不注入 Explorer，不打补丁，不修改现有桌面工具。Explorer 窗口结构不是稳定的公开扩展契约，必须在当前 Win11 与 Wallpaper 环境实测。

风险与边界：

- 单组折叠和滚动需要局部控制图标，不能仅隐藏整个桌面视图。
- 挖空边框只验证原生输入保留，不提供完整背景、裁剪或动画。
- Explorer 重启需重新建立关联。
- 混合 DPI、系统吸附和第三方排列会影响定位。
- 文件留在原位仍需处理分组身份与更新事件。

原生复用若无法满足核心体验，应报告限制，评估其他显示协调方式，不能未经确认改成搬移桌面文件。

## 10. 实际收纳小原型（当前）

用户在原路径方案前置验证未通过后，明确选择实际收纳并授权开始。当前默认入口使用 StorageWindow / ShortcutStore / ShortcutPanel；原诊断窗口保留在 `--legacy-probe`。

- 个人桌面根目录的 .lnk／.url 才会被收纳，固定单组最多 12 项。
- Storage/Default 保存运行内容及历史版本；Data/Groups/default.json 保存成员、位置和逐项搬移状态。
- VerifiedTransfer 用带删除权限的源文件句柄锁住文件，复制主数据及备用数据流、落盘校验、持久化完整副本标记后，通过同一文件句柄移除源文件。复制未完整确认不自动移除源文件；同名目标存在时不覆盖。
- 启动读记录后收纳；正常关闭归还。中断后据阶段、校验及完整副本标记恢复。归还冲突会阻止关闭并提示；强制退出后文件可能仍在 Storage。桌面像素位置尚未恢复。
- FileSystemWatcher 合并原位置的重建事件。同目标、启动参数及工作目录一致才自动接收新入口，旧版保留；版本目标变更、改名或参数改变先提示，尚不自动推断。
- 分区为单个分层桌面子窗口。WPF 仅离屏绘制到预乘 Alpha 位图，用 UpdateLayeredWindow 提交；背景 Alpha225，图标保持原始不透明度。移动只调用 SetWindowPos，不重建位图、不重排 Shell 图标，松开后保存坐标。
- 基础双击打开、折叠已接入；按最新反馈改为悬停立即展开、离开立即收起，图标有独立悬停及点击选中状态。拖入从只能收到放下通知的 WM_DROPFILES 改为 OLE IDropTarget，DragEnter 使折叠标题立即展开，DragLeave 收起，Drop 使用原有校验搬移。通过 Performed DropEffect=NONE、Logical Performed DropEffect=MOVE 告知 Shell 已由目标完成搬移，避免拖出方重复删除源文件。
- 最新增加约 150 毫秒的缓出折叠动画，悬停变化立即启动，从当前高度反向切换。完整内容位图缓存复用，逐帧裁剪并提交，不逐帧重绘文字和图标。
- 拖出采用鼠标捕获与拖动阈值，显示临时透明图标预览；松开前移除预览，通过实际命中的 Explorer 桌面窗口判断是否归还。只支持桌面，Esc、失去捕获或其他窗口上松开取消，不作为任意 Shell 目标的拖出实现。归还前先持久化解除分组意图，完成后归档成员，崩溃恢复不会重新收纳已归还项。同名冲突不覆盖，保持恢复记录；原路径恢复后由 Explorer 排列图标。
- 图标先解析显式图标资源，再从目标程序提取，最后回退到 Shell；相对资源保留原桌面上下文。Axolotl Launcher 未指定独立图标，目标 EXE 存在，本轮验证可从其资源读取原图标，且收纳副本像素一致，原快捷方式未改写。
- 主实例用项目内文件锁排他，避免两实例同时搬移。没有注册系统开机启动。
- 上述为早期收纳原型状态；当前常驻版的托盘、启动开关和桌面恢复见下一节。

验证：StorageTest 26 项通过，包括下载来源备用数据流、正常收纳归还、会话中断、同目标重建与旧版保留、不同目标冲突、复制不完整及文件占用，以及新增拖回解除分组、重启不再收纳、归还中断恢复和拖回冲突。StorageRenderTest 用项目样例在真实桌面连续移动 120 次，无位图重建或 Shell 重排；最近移动调用 p95 约 1.24 毫秒，仅代表该次 API 耗时，不等于拖动帧率或端到端延迟。

样例 UI 已验证归还、重新收纳；模拟原路径重建快捷方式，监听器自动吸收且保留旧版；正常关闭后 3 项均归还、活动存储副本为 0，进程退出码 0。真实桌面跨盘搬移、最终合成视觉、Win+D、Explorer 重启、双屏、托盘、普通文件和文件夹尚未验收或实现。

已通过原生 OLE 注册、Shell 文件数据对象拖入／拖离及实际收纳检查；即时悬停展开／收起、独立悬停和选中状态、同图标内不重复重画、拒绝不支持文件、优化搬移结果回执均通过。IconTest 检查默认图标、相对自定义资源、资源失效回退及 Axolotl 实际入口的只读副本。用户已确认这批实际交互正常。本轮新增展开／收起动画、动画不重建内容位图、拖动预览创建／移动／销毁检查通过；用户确认动画流畅、真实指针拖回桌面正常。中途反向切换及 Esc 取消未单独验收。

## 11. 托盘与桌面恢复（当前增量）

- ResidentTray 使用独立的隐藏顶层 HwndSource 和 Shell_NotifyIcon，不依赖 Explorer 内的分区窗口存活；TaskbarCreated 后重新登记。托盘菜单包含控制窗口、定位、归还、重新收纳、启动开关及退出。
- 真实控制窗口关闭时隐藏，明确退出才归还并关闭；归还失败时停止退出并显示问题。样例保留关闭即退出行为。启动参数 --background 用于登录后收起到托盘，有错误时保留控制窗口。
- 项目内文件锁仍负责排他搬移，当前用户专用 NamedPipe 只接收固定的 show 请求，重复启动唤回现有窗口，不执行任意命令。
- ShortcutPanel 识别原生窗口失效及父宿主变化，清理旧表面与 OLE 注册，保留成员和折叠状态，重新创建单个桌面子窗口并登记拖入。健康状态每 2 秒只检查原生句柄和父级，不重建画面。挂接成功前不开始新的收纳。
- 独立消息源接收显示、唤醒、解锁和 Explorer 通知，合并后检查环境；操作期间延后处理。DesktopPlacement 根据实际显示器工作区域选择位置与缩放，避免负坐标、屏幕空隙和断开显示器使分区不可达。
- StartupRegistration 默认不登记；开关只修改 HKCU Run 中本项目独立的一个值，指向项目内 exe，并显式传入根目录与 --background。不会覆盖内容被其他程序修改的入口。系统注册信息由 Windows 管理，源码、配置、文件、缓存、诊断仍在项目内。
- 24 项 ResidentTest 检查通过；26 项收纳测试及面板移动、动画与 OLE 回归通过。真实重复启动唤回检查通过，用户确认托盘与 Win+D 正常。真实 Explorer 重启、休眠、双屏插拔和登录启动未验收，模拟测试不等同现场通过。常驻版退出 UI 复测因用户按 Esc 停止界面操作而未执行。

操作和验证边界见《常驻与恢复验证.md》，报告在 TestData/Resident。
